# ⚖️ 01-02. 공공데이터 및 지도 API 상업적 이용 & 위치정보법 2단계 법률 검토서

> **문서 목적**: 이어봄(Eobom) 플랫폼이 **보건복지부 공공데이터**(전국 장례식장 현황 API · 봉안시설·자연장지 CSV)와 **카카오 로컬/맵 API**로 전국 장사시설 데이터를 모아 영리 플랫폼(업체 문의 리드 수수료 모델, → `01-05`)으로 쓸 때의 법적 적합성을 검토합니다. 공공데이터법과 **「위치정보의 보호 및 이용 등에 관한 법률(위치정보법)」** 두 층위로 나눠 봅니다.
> 🟡 법률 자문 전 검토 의견입니다 — 게시 전 법률 자문(`00-22` A-5)과 묶어 다시 확인합니다. 처음 결론과 폐기된 안은 문서 끝 **부록: 경위**.

## 📌 1. 검토 요약 및 2단계 규제 구분 (Dual-Layer Regulatory Framework)

| 규제 층위 | 관련 법률 및 약관 | 판단 | 현재 조치 |
| :--- | :--- | :---: | :--- |
| **Layer 1: 공공데이터 영리이용** | • 공공데이터법 제3조 · 제26조<br>• 실제 신청 데이터 3종의 이용허락범위 = 제한 없음 | 허용 | 출처 표시 의무 없음(§4) |
| **Layer 2: 위치기반서비스 (LBS)** | • 위치정보법 제9조 | 현위치 거리 정렬은 **신고 대상** | 트랙 A(현위치 정렬) **2026-09-10 켬** · 트랙 B(지역 선택)는 폴백으로 유지 · **신고는 실서비스 개시 전**(`00-22` B-1) |
| **수익 모델** | • 공공데이터 2차 가공 서비스 | 허용(검토 의견) | 정보는 무료 개방 + 업체 문의 리드 수수료(`01-05`) |

> **결론:** 공공데이터는 영리 이용이 허용됩니다. 실시간 현위치 기반 거리 정렬(트랙 A)은 위치정보법상 사업자 신고 대상이며,
> 2026-09-10 사람 결정으로 **기능을 먼저 켜고 신고는 실서비스 개시 전에 하기로** 했습니다(`00-22` A-3·B-1).
> 위치를 받지 못하면 지역 선택(트랙 B)으로 떨어집니다. **Layer 2에서 남은 것은 신고 하나입니다.**

## 🏛️ 2. 2단계 법률 검토 및 규제 분석

### 2.1 Layer 1: 공공데이터법 & 카카오 API 저작권 검토 (100% 합법)
1. **보건복지부 e하늘장례정보 데이터 (data.go.kr)**:
   * `공공데이터법 제3조 및 제26조`에 의거, 공공기관은 영리 목적 이용을 제한할 수 없으며 **공공누리 제1유형(출처 표시 조건 하 2차 가공 및 영리이용 허용)**이 적용됨.
2. **카카오 로컬 REST API & Maps SDK**:
   * `Kakao Developers 서비스 약관 제9조`에 의거, 상업용 앱/웹 내 지도 렌더링 및 핀 표시가 100% 허용됨.

### 2.2 Layer 2: 위치정보법(방송통신위원회/KISA) 규제 분석 및 대응 트랙

#### 데이터셋과 위치정보법 — 장례식장 데이터는 공공 API로 확정 (2026-09-09)

공공데이터포털 API 중에는 *"위치기반서비스사업자 신고필증 미첨부 시 반려"* 요건이 붙은 데이터셋이 있습니다.
이 요건은 공공데이터법이 아니라 **위치정보법 제9조**에서 옵니다. 🔴 모든 데이터셋에 붙는 것은 아니며,
장례식장 정본으로 쓰는 데이터셋은 **신고필증 없이 승인**됐습니다.

| | 값 |
| :--- | :--- |
| 데이터셋 | **보건복지부_보건·복지현황_전국 장례식장 현황** |
| End Point | `https://apis.data.go.kr/1352000/ODMS_DATA_04_1` (상세기능 `/callData04_1Api`) |
| 심의여부 · 처리상태 | **심의 · ✅ 승인**(개발계정) — 🔵 **신고필증 없이 승인됨** |
| 활용기간 | **2026-08-07 ~ 2028-08-07** · 일일 트래픽 10,000 |
| 이용허락범위 | 제한 없음 · 활용목적 "웹 사이트 개발"(상업적 이용 명시) |
| 데이터 기준일 | **2026-04-01** · 포맷 **XML 전용** · `totalCount` **1,080** |

- 🔴 **`systems.md` §3의 "e하늘 장례식장 현황 OpenAPI ❌ 배제"는 다른 데이터셋입니다.** 배제 판정이 뒤집힌 것이 아니라 **요건이 다른 문을 찾은 것**이며, e하늘 쪽 판정은 그대로 유효합니다.
- 🔵 **Layer 2와 충돌하지 않습니다** — 이 API가 주는 것은 시설의 주소·전화이고 **위경도가 없습니다.** 좌표는 주소 지오코딩으로 채우며, 이는 트랙 B(유저 GPS 미채집)의 범위 안입니다.
- ✅ **사람 확정(09-09): 장례식장은 이 API를 정본으로 합니다.** 카카오 로컬 API는 **보강**(좌표·`kakaoPlaceId`·통용명)이며, 🔴 **XML에 없는 시설은 DB에서 삭제**합니다. 경위·실측은 `systems.md` §2·§3.

#### 두 트랙의 법적 구분

```
                  【 위치정보법 규제 적용 기준 】
                                   │
              ┌────────────────────┴────────────────────┐
              ▼                                         ▼
【 트랙 A: 실시간 현위치 정렬 】              【 트랙 B: 지역/검색어 선택 】
 • 유저 위치(`geolocation`) 수신              • 유저 위치 미수신 ("강남구" 선택)
 • 위치기반서비스 사업자 신고 대상            • 위치정보법 신고 대상 아님(검토 의견)
 • 2026-09-10 켬 · 신고는 개시 전              • 트랙 A의 폴백 경로
```

1. **[트랙 A] 실시간 유저 위치 기반 거리 정렬 (`navigator.geolocation`)**:
   * 유저의 현재 위치를 받아 시설과의 거리를 계산하는 방식은 위치정보법상 **위치기반서비스**에 해당합니다.
   * **조치:** 방송통신위원회 및 KISA에 위치기반서비스 사업자 신고(개인위치정보 미수집 시 간이신고). 🟡 *"소요 2~4주"* 는 조문을 대조한 값이 아니라 처음 검토 때 적어둔 값입니다(`00-22` B-1).
2. **[트랙 B] 지역/검색어 선택 기반 지도 탐색**:
   * 유저의 위치를 받지 않고, 유저가 **"서울 강남구" 같은 지역이나 시설명을 직접 검색·선택**해 카카오 지도 핀을 그리는 방식입니다.
   * **법적 평가:** 개인위치정보를 처리하지 않으므로 위치기반서비스 사업자 신고 대상이 아닌 것으로 봅니다(검토 의견). 지금은 트랙 A가 실패했을 때의 정상 경로입니다.

## 💰 3. 비즈니스 수익 모델(Monetization)과의 법적 구별

영리 활동이 공공데이터 이용과 충돌하지 않는 구조는 다음과 같습니다:

```
[ 보건복지부 공공데이터 (무료) ] ➔ [ 이어봄 2차 가공 (검색·지도·정렬) ]
                                                │
               ┌────────────────────────────────┴────────────────────────────────┐
               ▼                                                                 ▼
【 유족 / 일반 사용자 】                                        【 장례식장 · 봉안 · 수목장 사업자 】
 • 전국 시설 위치·기본 정보 무료 검색                        • 업체 문의 리드 수수료(→ 01-05)
 • 업체 문의 무료                                            • 그 밖의 제휴 혜택·대가는 결정대기(→ 01-01 §3.3)
```

* **법적 정당성:** 공공데이터 자체를 유저에게 파는 것이 아니라, 정보는 무료로 개방하고 **사업자에게 연결한 문의(리드)에서 수수료**를 받는 구조입니다.
* **타사 사례(참고):** 🟡 출처를 확인하지 않은 사례이며 근거로 쓰지 않습니다.
  * **직방/다방:** 국토교통부 아파트 실거래가 공공데이터 ➔ 부동산 입점 수수료
  * **야놀자/여기어때:** 한국관광공사 숙박 데이터 ➔ 숙박업소 입점/수수료
  * **카카오 T:** 전국 택시/주차장 공공 정보 ➔ 호출 연결 수수료
