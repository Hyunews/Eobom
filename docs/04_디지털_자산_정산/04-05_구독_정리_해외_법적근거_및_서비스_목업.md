# 04-05 구독 정리 — 해외 법적 근거 조사 및 서비스 목업

> **[조사 + 목업 · 2026-09-22 신설]** `04-04`의 후속. 개발자 질문 3가지에 답합니다:
> ① 생전 구독 목록은 **직접 적어야 하나**, 해외도 그런가 ② 생전에 적은 것이 **사후에 효력을 갖는
> 해외 법적 근거** ③ **이상적 방향 / 현실적 방향** 목업.
> 🔴 **계획 문서입니다. 확정 스펙이 아닙니다.** 확정되면 `04-01`로 승격합니다(`04-04`와 같은 규칙).
> 🔵 용어는 쉬운 말로 씁니다. 원어는 괄호에 한 번만 적습니다.

## 📌 1. 결론 먼저

1. **목록은 결국 본인이 적습니다. 다만 "기억해서"가 아니라 "보고 옮겨 적기"입니다.** 구독 내역이
   이미 모여 있는 곳이 4군데 있습니다(§2.3). 해외 서비스도 대부분 **직접 적는 워크북 방식**이고,
   자동으로 찾아주는 앱은 **본인이 살아서 쓰는 가계부 앱**이지 사후용이 아닙니다(§2.1).
2. 🔴 **어느 나라에도 "생전에 적은 구독 목록" 자체가 해지 효력을 내는 법은 없습니다.**
   법이 정해 주는 것은 **"누가 고인 대신 권한을 갖는가"** 까지입니다(§3.1). 목록은 **정보**이고,
   실제 해지는 **상속인 자격** 또는 **결제 수단 정지**로 이뤄집니다.
3. 🔴 **`04-04` §2.2 정정** — Apple 유산 관리자는 **구독·인앱결제·결제 정보에 접근할 수 없습니다**
   (§3.3). *"생전에 지정하면 반나절"* 은 사진·메모 같은 **데이터**에 해당하는 말이고,
   **구독 해지에는 해당하지 않습니다.**
4. 🟡 **한국은 법 구조상 독일과 같습니다** — 상속인이 고인의 계약을 통째로 이어받습니다(민법 제1005조).
   그래서 유족은 **상속인으로서** 해지할 수 있습니다. 🔴 단, **상속포기를 생각 중인 유족이 해지하면
   상속을 받아들인 것으로 볼 위험**이 있습니다(§3.4). 이건 화면 문구로 반드시 알려야 합니다.

## ✍️ 2. 질문 ① — 직접 적어야 하나? 해외도 그런가?

### 2.1 해외 서비스가 목록을 만드는 방식은 셋입니다

| 방식 | 어떻게 | 대표 | 사후에 쓸 수 있나 |
| :--- | :--- | :--- | :--- |
| **가. 워크북형** | 항목별 질문에 답하며 **직접 적음**(보험·계좌·구독·유언…) | Everplans · GoodTrust | ✅ 가족에게 넘겨주는 용도 |
| **나. 은행 연동 자동 탐지** | 은행·카드를 앱에 연결하면 **반복 결제를 자동으로 찾아냄**(Plaid라는 연결 중개 회사를 거침) | Rocket Money 등 가계부 앱 | ❌ **본인 인증 기반** — 살아 있는 본인만 씀 |
| **다. 플랫폼 지정** | Apple·Google 설정 안에서 **"내가 죽으면 이 사람에게"** 를 지정 | Apple 유산 관리자 · Google 비활성 계정 관리자 | 🟡 데이터만. **구독은 안 됨**(§3.3) |

🔴 **"가"가 주류입니다.** "나"는 생전에 구독을 줄이는 도구이고, 사후 정리 서비스가 이 방식을 쓰는 사례는
조사에서 확인되지 않았습니다. 🔵 우리가 "나"를 하지 않는 이유는 `04-04` §3.4(계좌·카드 연동 배제)입니다.

### 2.2 일본 정부 기관의 권고도 "직접 적기"입니다

일본 **국민생활센터**(2024-11)는 사후 구독 요금이 계속 나가는 상담이 잇따르자 네 가지를 권고했습니다:
① 휴대폰 잠금 해제 방법을 가족이 알게 해 두기 ② **서비스 이름·아이디를 목록으로 정리해 두기**
③ 엔딩노트 활용 ④ 플랫폼의 사후 지정 기능 쓰기. 🔵 **우리 P1·P2와 순서까지 같습니다.**
(🔴 ②의 비밀번호 기록은 우리는 받지 않습니다 — `04-01` §0.5.)

### 2.3 "기억해서"가 아니라 "여기 보고 옮겨 적기" — 구독이 모여 있는 4곳

| # | 어디서 보나 | 무엇이 나오나 | 못 잡는 것 |
| :---: | :--- | :--- | :--- |
| 1 | **아이폰** 설정 → 내 이름 → 구독 | 앱스토어로 결제한 구독 **전부, 서비스 이름으로** | 앱 밖에서 결제한 것 |
| 2 | **구글 플레이** → 결제 및 정기 결제 → 정기 결제 | 구글 플레이로 결제한 구독 전부 | 〃 |
| 3 | **어카운트인포**(금융결제원 계좌정보통합관리) | 계좌 **자동이체** 목록 | 카드 정기결제 일부·해외 결제 |
| 4 | **카드사 앱** 정기결제/이용내역 · **통신사 앱** 소액결제 | 카드로 매달 나가는 것 · 휴대폰 요금에 합쳐진 것 | — |

🔴 **1·2번이 `04-04` §3.3의 가장 큰 구멍(`APPLE.COM/BILL` 한 줄)을 메웁니다.** 카드 명세로는 알 수 없던
인앱결제가 **본인 휴대폰에서는 이름으로 다 보입니다.** 사후에는 못 보지만 **생전에는 1분이면 봅니다.**
→ 그래서 P1 화면은 **"이 4곳을 열어 보고 옮겨 적으세요"** 순서 안내가 핵심입니다(§4.2).
🆕 국내 구독 탐지 앱(왓섭·토스·뱅크샐러드)과 삼성 디지털 유산 조사는 **`04-04` §2.4-1**.

## ⚖️ 3. 질문 ② — 사후 효력의 해외 법적 근거

### 3.1 먼저 큰 그림 — 법이 해 주는 일은 두 종류뿐입니다

| 종류 | 무엇을 정하나 | 해당 법 |
| :--- | :--- | :--- |
| **가. 권한 이전** | 고인이 죽은 뒤 **누가** 계정·계약에 대해 말할 자격이 있나 | 미국 RUFADAA · 캐나다 · 프랑스 제85조 · 스페인 제96조 · 독일 판례 |
| **나. 해지 쉽게** | 구독을 **끊기 쉽게** 만들라는 사업자 의무 | 미국 FTC 규칙(무효화 후 재추진) · 영국 DMCC법 |

🔴 **"나"에는 사망 특칙이 없습니다** — 살아 있는 소비자 보호용입니다. 사후 구독과 직접 이어지는 것은 **"가"뿐**입니다.

### 3.2 나라별 정리

#### 🇺🇸 미국 — RUFADAA(개정 통일 디지털자산 수탁자 접근법)

- **거의 전 주가 채택**(2026 기준 47개 주 + 워싱턴DC, 나머지도 유사법). 연방법이 아니라 **주법**입니다.
- 🔴 **우선순위 3단계** — 이것이 해외 법 중 가장 중요한 구조입니다:

| 순위 | 무엇 | 예 |
| :---: | :--- | :--- |
| **1** | **플랫폼 안의 사후 지정 도구**(온라인 도구) | Google 비활성 계정 관리자 · Apple 유산 관리자 · Facebook 추모 계정 관리자 |
| **2** | **유언장·신탁·위임장**에 적은 지시 | "내 넷플릭스는 해지해 달라" |
| **3** | 플랫폼 **이용약관** | 1·2가 없을 때 |

- 🔵 **기본값은 "목록만"** — 고인이 동의하지 않았으면, 유언 집행인은 이메일의 **보낸 사람·날짜 목록**만 받고
  **본문은 못 봅니다.** 🟢 구독 확인에는 목록으로 충분합니다(어느 회사에서 청구서가 왔는지는 보이므로).
- 사업자는 서류를 받으면 **60일 안에** 응하거나 거절해야 합니다.
- 🔴 **2순위에 주목** — 미국에서는 **유언장에 적은 구독 지시가 법적 효력을 가집니다.** 한국에서는 유언의
  형식 요건이 엄격해 같은 효과를 내기 어렵습니다(§3.4 · §6 #7).

#### 🇨🇦 캐나다 — 통일 디지털자산 접근법(2016)

- 캐나다 통일법 회의가 2016년 모델법을 만들었고, **사스캐처원주(2020-06 시행)** · **프린스에드워드아일랜드주(2022-01)** 가
  채택했습니다. 구조는 미국과 비슷합니다(수탁자 접근 + 본인 의사 존중). 🟡 채택 주가 **아직 적습니다.**

#### 🇩🇪 독일 — 법률이 아니라 대법원 판결(2018)

- **연방대법원 2018-07-12 판결**(III ZR 183/17, 페이스북 사건): 15세에 숨진 딸의 계정에 부모가 접근하려 한 사건.
- 🔴 결론: **계정 이용 계약은 상속된다.** 민법 제1922조(포괄승계 — 상속인이 고인의 법률관계를 통째로 이어받음)에 따라
  *"디지털 유산을 종이 유산과 다르게 다룰 이유가 없다."*
- 🔵 **한국과 구조가 같습니다** — 한국 민법 제1005조도 포괄승계입니다(§3.4). 한국에는 같은 판결이 **아직 없습니다.**

#### 🇫🇷 프랑스 — 정보처리자유법 제85조 "사후 지시"

- 🔴 **생전 지시에 법적 효력을 명시한 가장 직접적인 법입니다.** 누구나 사후 자기 데이터의 **보존·삭제·전달**에 대한 지시를 남길 수 있습니다.
- 지시는 두 종류:
  - **일반 지시** — 모든 데이터 대상. 개인정보 감독기관(CNIL)이 **인증한 제3자**에게 등록.
  - **특정 지시** — 특정 사업자 대상. **그 사업자에게 직접** 등록. 🔴 **약관 동의만으로는 성립하지 않고 따로 동의해야 합니다.**
- 지시를 **실행할 사람을 지정**할 수 있고, 그 사람이 사업자에게 요구할 권한을 가집니다.
- 지시가 없으면 **상속인이 계정을 닫을 수 있습니다.**
- 🔵 **이어봄에 주는 힌트** — "인증받은 제3자가 생전 지시를 보관" = 이상적 방향(§4.1)의 원형입니다.

#### 🇪🇸 스페인 — 개인정보보호법 제96조 "디지털 유언"

- 가족·상속인이 사업자에게 고인 콘텐츠에 대한 **사용·처리·삭제 지시**를 할 수 있습니다.
- SNS 계정은 **고인이 정해 둔 것이 있으면 그것을 따릅니다.**
- 🟡 지시의 유효 요건·**등록 방법은 시행령으로 정한다**고 돼 있습니다(시행 상태는 추가 확인 필요).

#### 🇬🇧 영국 — 특별법 없음, 대신 "한 번에 알리기" 제도

- 디지털 유산 특별법은 **없습니다.** 대신 **알리는 수고를 줄이는 창구 두 개**가 있습니다:
  - **Death Notification Service** — **민간**(은행권 공동). 양식 **한 번**으로 약 **30개 은행·카드사**에 동시 통지.
  - **Tell Us Once** — **정부**. 세무·연금·운전면허·여권·지자체에 한 번에 통지. 🔴 은행·통신·구독 회사는 **포함 안 됨.**
- **DMCC법(2024) 구독 규제** — 갱신 전 알림·쉬운 해지 의무. 🟡 **2027년 봄 시행 예정**(두 차례 연기).
  사망 특칙은 확인되지 않았습니다.

#### 🇯🇵 일본 — 법 없음, 약관에 맡김

- 디지털 유산 법이 **없고**, 개인정보보호법은 **죽은 사람에게 적용되지 않습니다** — 한국과 같습니다.
- 🔴 **주목할 경고** — 일본 변호사들은 *"상속포기를 생각한다면 구독 해지도 하지 말라"* 고 조언합니다.
  해지가 **상속재산 처분**으로 보여 **상속을 받아들인 것**이 될 수 있어서입니다. **한국에도 같은 조문이 있습니다**(§3.4).

#### 🇺🇸 참고 — 미국 FTC "클릭 한 번 해지" 규칙

- 2024년 제정 → **2025-07 연방항소법원이 절차 위반으로 무효화** → **2026-03 FTC가 규칙 제정 재착수**.
  🟡 사망 특칙 없음. 살아 있는 소비자용입니다.

### 3.3 🔴 `04-04` §2.2 정정 — Apple·Google 지정 도구는 구독을 못 건드립니다

| | Apple 유산 관리자 | Google 비활성 계정 관리자 |
| :--- | :--- | :--- |
| 넘겨받는 것 | iCloud 사진·메모·메일·백업 등 **데이터** | 데이터 내려받기(최대 10명) |
| 🔴 **못 받는 것** | **구독 · 인앱결제 · 결제 정보** · 구매한 영화·음악 · 저장된 비밀번호 | — |
| 구독은? | 🔴 **대상 아님** | 🔴 **카드 만료 때까지 계속 청구**될 수 있음. 구독이 살아 있으면 장기 미사용 삭제에서도 **제외** |

→ **플랫폼 도구로는 구독이 안 끊깁니다.** 끊는 길은 **(가) 상속인이 사업자에 해지 요청** 또는
**(나) 카드사·통신사에 결제 정지**뿐입니다. P2(플랫폼 안내)는 **데이터 인계용**으로 의미를 낮춰 잡아야 합니다.

### 3.4 한국에 대입하면 — 법률 자문에 가져갈 질문

| 해외 | 한국 대응 | 판단 |
| :--- | :--- | :--- |
| 독일 판례(계약 상속) | **민법 제1005조** 포괄승계 — 같은 구조 | 🟢 상속인은 해지할 자격이 있다고 **볼 여지가 큼** |
| 미국 2순위(유언장 지시) | **민법 제1060조** 유언은 법이 정한 방식만 효력 | 🔴 이어봄 화면에 적은 목록은 **유언이 아님** → **참고 정보** |
| 프랑스 제85조(사후 지시) | 대응 법 **없음**. 개인정보보호법은 산 사람만 | 🔴 법적 효력 없음 |
| 일본 경고(해지=상속 승인) | **민법 제1026조 1호**(상속재산 처분 → 단순승인 간주) · **제1019조**(3개월 안에 포기) | 🔴 **유족에게 반드시 알려야 함** |

> 🔴 **가장 중요한 한 줄**: 한국에서 생전 구독 목록은 **"법적 지시"가 아니라 "가족에게 남기는 안내문"** 입니다.
> 효력은 목록이 아니라 **유족의 상속인 자격**에서 나옵니다. 그래서 화면에 *"이 목록은 법적 효력이 없습니다"* 를
> **사실로** 적어야 합니다(`00-39` 규칙 6-2 — 평가하는 말 금지).

## 🖼️ 4. 질문 ③ — 목업: 이상적 방향 vs 현실적 방향

### 4.1 이상적 방향 — "법과 제도가 갖춰졌다면"

**전제 조건(지금 한국에 없는 것 4가지)**

| # | 필요한 것 | 해외 원형 |
| :---: | :--- | :--- |
| A | **생전 지시에 효력을 주는 법** — "내 구독은 사후 해지"가 법적 지시가 됨 | 프랑스 제85조 · 미국 RUFADAA 2순위 |
| B | **이어봄이 "인증된 보관 기관"** 이 됨 | 프랑스 CNIL 인증 제3자 |
| C | **사업자 공동 수신 창구** — 사망 통지를 한 번에 받는 곳 | 영국 Death Notification Service · Life Ledger |
| D | **어카운트인포 유족 창구** — 상속인이 고인 자동이체를 조회·해지 | (해외에도 완전한 원형 없음) |

**생전 화면**

```
┌─ 내 구독 정리 ─────────────────────────────┐
│ [휴대폰에서 불러오기]  앱스토어·구글플레이 구독을   │
│                      본인 동의로 가져옵니다        │
│                                             │
│  넷플릭스      월 17,000원   ◉ 사후 해지        │
│  유튜브 프리미엄 월 14,900원  ◉ 사후 해지        │
│  네이버 클라우드  월 3,300원   ◉ 가족에게 넘김    │
│                                             │
│ [사후 지시로 등록]                              │
│  → 인증 기관(이어봄)에 등록됩니다. 법적 효력이 있습니다. │
│  실행할 사람: 김○○ (가족 지정 수락함)             │
└─────────────────────────────────────────────┘
```

**사후 화면(유족)**

```
┌─ 고인 구독 정리 ─────────────────────────────┐
│ 사망 사실 통지 1회 → 제휴 사업자 12곳에 전달됨     │
│                                             │
│  넷플릭스       해지 완료   09-25              │
│  유튜브 프리미엄  해지 요청 중  응답 대기 3일째    │
│  네이버 클라우드  가족 이전 완료                  │
│  (어카운트인포) 자동이체 4건 확인 → 해지 요청 가능  │
└─────────────────────────────────────────────┘
```

🔴 **A~D 중 이어봄이 스스로 만들 수 있는 것은 C(제휴)뿐**이고, 그것도 `pending-approvals`의 제휴 구조 재설계가 선행입니다.

### 4.2 현실적 방향 — "지금 법 아래에서"

**원칙**: 목록은 **안내문**, 해지는 **유족이 상속인으로서 직접**, 이어봄은 **순서와 연락처를 알려줌**(`04-01` §0.5 그대로).

**생전 화면(P1)**

```
┌─ 내 구독 목록 ──────────────────────────────┐
│ 구독 내역은 아래 4곳에서 볼 수 있습니다.          │
│  ☐ 아이폰: 설정 → 내 이름 → 구독               │
│  ☐ 구글 플레이: 결제 및 정기 결제 → 정기 결제      │
│  ☐ 어카운트인포: 자동이체 조회  [바로가기]         │
│  ☐ 카드사 앱 · 통신사 앱 소액결제                │
│                                             │
│ [+ 목록에서 고르기]  [+ 직접 입력]               │
│                                             │
│  넷플릭스      결제: 앱스토어     원하는 처리: 해지 │
│  유튜브 프리미엄 결제: ○○카드     원하는 처리: 해지 │
│  네이버 클라우드  결제: 통신요금    원하는 처리: 가족 판단 │
│                                             │
│ ⓘ 이 목록은 법적 효력이 없습니다.                 │
│   가족 지정을 수락한 분에게 사후에 공개됩니다.      │
└─────────────────────────────────────────────┘
```

- 금액·결제일은 **선택 입력**, 카드번호·비밀번호는 **입력란 자체가 없음**(`04-04` §4.1).
- "원하는 처리"는 **해지 / 유지 / 가족 판단** 세 가지.

**사후 화면(P3·P4, 가족 지정 수락자)**

```
┌─ 고인이 남긴 구독 목록 ──────────────────────────┐
│ ⚠ 상속포기를 검토 중이면 해지 전에 먼저 확인하세요.    │
│   해지가 상속을 받아들인 것으로 볼 수 있습니다.        │
│   (민법 제1026조 · 포기 기한 3개월) [자세히]        │
│                                             │
│  넷플릭스   결제: 앱스토어                        │
│   해지 방법: 애플 고객지원에 사망 사실 알림 [연락처]   │
│   진행: ○ 안 함  ● 요청함  ○ 완료                 │
│                                             │
│  유튜브 프리미엄  결제: ○○카드                     │
│   해지 방법: 구글 고인 계정 요청 양식 [바로가기]      │
│   진행: ● 안 함                                 │
│                                             │
│ 응답이 없을 때: 카드사에 결제 정지 요청 [안내]        │
│   (같은 카드의 다른 자동결제도 함께 멈춥니다)          │
└─────────────────────────────────────────────┘
```

### 4.3 두 방향 비교

| | 이상적 | 현실적 |
| :--- | :--- | :--- |
| 목록 만들기 | 휴대폰에서 **불러오기** | 4곳 **보고 옮겨 적기** |
| 목록의 법적 성격 | **사후 지시**(효력 있음) | **안내문**(효력 없음) |
| 해지하는 사람 | 등록된 실행인 → 이어봄이 일괄 통지 | **유족이 직접**, 이어봄은 순서 안내 |
| 진행 추적 | 사업자 응답이 **자동 반영** | 유족이 **직접 체크** |
| 막힌 이유 | 법(A)·인증(B)·제휴(C)·금융 창구(D) | 없음 — **지금 착수 가능**(P1) |

🔵 **현실적 방향을 먼저 만들어도 이상적 방향으로 갈 때 버리는 것이 없습니다.** 목록 데이터(항목·결제 수단·원하는 처리)는
그대로 두고, 법이 생기면 "안내문" 표시를 "사후 지시"로 바꾸는 구조입니다.
