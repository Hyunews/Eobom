### 2.2 🔵 D-Day 재정렬 — **충돌이 아니라 미이행 스펙의 완성입니다**

**처음에는 충돌로 보였습니다.** `07-02` §3 제목이 그대로
***"표시 순서 — 기한 순이 아니라 판단 순"*** 이고, 이 원칙은 `00-09` §3.1 · `00-26` §3.1 ·
`00-23` §4.2가 인용해 **사이드바 메뉴 순서까지 결정**했습니다.

**그런데 `07-01`을 보니 이야기가 달랐습니다.**

| 무엇이 | 폐기됐나 |
| :--- | :--- |
| **근거 없는 고정 D+N 라벨** (`D+14일`·`D+60일`) | ✅ **폐기됨**(`07-01` §1.3·§4.2). 라벨과 본문이 모순됐고 상속세는 **라벨이 실제의 1/3**이었습니다 |
| **시간축 자체** | ❌ **폐기된 적 없습니다** |

> 🔵 **오히려 `07-01` §4.2가 이렇게 지시해 두었습니다** —
> *"화면에는 **계산된 실제 날짜**를 보여줍니다 — **'2026년 11월 30일까지'**.

**§3이 반대한 것은 "순수 기한 오름차순"입니다** — *"3개월(상속포기)보다 1개월(사망신고)이
먼저 오면 안 된다"*. 이 걱정은 정렬을 시간축으로 바꿔도 **§4의 설계로 그대로 해소됩니다.**

### 2.3 ✅ 되돌릴 수 없는 것 강조 — **원칙은 있고 화면이 없습니다**

`07-02` §3의 원문이 *"기한 순이 아니라 **판단 순, 되돌릴 수 없는 것부터**"* 입니다.
데이터에도 이미 **`severity: CRITICAL` 7건**이 들어 있습니다.

| | 상태 |
| :--- | :--- |
| 원칙 | ✅ 있음(`07-02` §3) |
| 데이터 | ✅ 있음(`careGuideTasks.json`, CRITICAL 7 / NORMAL 11 / INFO 5) |
| 정렬 반영 | ✅ 있음(`CareGuidePage.tsx:32` `SEVERITY_ORDER`) |
| **시각적 강조** | 🔴 **그룹 헤더 색상뿐 — 항목 자체에는 표시가 없습니다** |
| 상단 고정 배너(§3.1) | 🔴 **미구현** |

> 🔴 **지금은 스크롤해서 CRITICAL 그룹에 도달한 사람만 압니다.** `07-02` §3.1이
> *"유족은 체크리스트를 끝까지 스크롤하지 않는다"* 고 이미 경고했는데 그 대책(고정 배너)이

> 지금보다 더 중요해집니다.** 설계는 §5.

## 🔴 3. 선행 과제 — **화면이 사망일을 받지 않습니다**

`CareGuidePage.tsx`의 state는 `tasks`·`expandedIds` 둘뿐이고 `deathDate`가 없습니다.
**기준일이 없으면 D-Day도, `07-01` §4.2가 지시한 실제 날짜 표시도 불가능합니다.**

### 3.1 🟡 `Deceased` 미확정에 걸리지 않게 하는 법

`00-12`의 `Deceased` 모델은 아직 미확정이고 04·05가 거기 묶여 있습니다.
**그런데 이 화면에 필요한 것은 날짜 하나뿐입니다.**

| 안 | 내용 | 판정 |
| :--- | :--- | :---: |
| A | `Deceased` 확정을 기다린다 | ❌ **무기한 대기.** 이 화면의 가치가 그때까지 잠깁니다 |
| B | **날짜 하나만 화면에서 입력받아 브라우저에 보관** | 🟡 **권고** |
| C | 서버에 사망일만 저장하는 모델 신설 | ❌ `Deceased`와 충돌합니다. **두 번 만들게 됩니다** |

> 🟡 **B안 권고 이유**: 사망일은 **고인의 정보가 아니라 이 유족의 화면 설정**으로 다루면
> 개인정보 수집 없이 기능이 섭니다. `07-01` §4.1이 *"체크 상태는 지금도 React state라
> 새로고침하면 사라진다"* 고 한 것과 같은 층위입니다.
> 🔴 **다만 "저장되지 않습니다"를 명시**해야 합니다 — `06-04` ⑨가 같은 함정을 겪었습니다.
> 🔵 `Deceased`가 확정되면 그때 값을 승계하면 됩니다. **B는 C로 가는 길을 막지 않습니다.**

### 3.2 🔴 입력하지 않은 유족을 쫓아내지 않습니다

**사망일 입력을 강제하면 안 됩니다.** `care-guide`는 `00-26` §4.2-1이 정한
**유일한 무로그인 화면**이고, 진입 장벽을 세우면 그 취지가 깨집니다.

> 🟡 **미입력 = 기본 상태.** 날짜가 없으면 **구간 이름만으로 그룹핑**하고
> (*"장례 기간"·"1개월 안에"·"3개월 안에"*), 입력하면 **각 항목에 실제 마감일**이 붙습니다.
> 상단에 *"사망일을 넣으시면 언제까지인지 날짜로 알려드립니다"* 정도의 권유만 둡니다.

### 3.3 🔴 "안 날" 문제는 그대로 남습니다

`07-01` §4.3 — **상속포기 3개월의 기준일은 사망일이 아니라 "상속개시 있음을 안 날"** 이고
그 판단은 법률 판단입니다. 사망일로 계산해 보여주되 **해당 항목에는 항상
*"기준일이 다를 수 있습니다"* 를 병기**하고 02 상담으로 연결합니다. **이건 §4.3 그대로입니다.**

### 4.1 🟡 5개 구간

| 구간 | 라벨 | 담기는 것(`07-02` §2 기준) |
| :---: | :--- | :--- |

| **2** | **1개월 안에** | 사망신고, 건강보험 자격상실·장제비 |
| **3** | 🔴 **3개월 안에 — 되돌릴 수 없음** | 안심상속🔴, 재산·채무 조사🔴, 한정승인/상속포기🔴, 특별한정승인🔴, 채권자 공고🔴, 유언 검인🔴 |
| **4** | **6개월 안에** | 상속세·취득세·소득세, 자동차 이전등록, 상속등기 |
| **5** | **그 이후 / 기한 여유** | 유족연금(5년), 각종 연금, 보험금, 계좌·명의 정리 |

> ✅ **구간 3이 통째로 CRITICAL입니다.** 시간축으로 정렬해도 **되돌릴 수 없는 것이 한 덩어리로
> 모입니다** — `07-02` §3이 걱정한 분산이 실제로는 거의 안 일어납니다.
> ⚠️ **예외 2건**: 24시간 제한(구간 1)과 유언 검인(*"지체 없이"*)이 밖에 있습니다. §5로 처리합니다.

### 4.2 🔴 구간 안의 순서는 **여전히 severity 우선**

**구간 내부에서까지 기한 순으로 하면 `07-02` §3을 정말로 어깁니다.**

```
정렬 = 구간(시간축) → severity(CRITICAL→NORMAL→INFO) → 기한
```

### 4.3 🔴 상단 고정 배너는 **정렬과 무관하게 항상 최상단**

`07-02` §3.1이 이미 문구까지 확정해 뒀습니다 — *"고인에게 빚이 있을 수 있다면, 3개월 안에
결정해야 합니다."* **미구현 상태이고, 이번에 반드시 함께 넣습니다.**

> 🔴 **정렬 방식을 바꾸는 이번이 이 배너가 가장 필요한 시점입니다.** 구간 1·2를 보던
> 유족이 구간 3까지 스크롤하지 않으면 그대로 3개월이 지나갑니다.

## ⭐ 5. 강조 체계 — **"되돌릴 수 없음"을 항목마다**

### 5.1 🟡 3단 표기

| severity | 표시 | 뜻 |
| :--- | :--- | :--- |
| **`CRITICAL`** | ⭐ + **"되돌릴 수 없음"** 글자 배지 + 좌측 굵은 테두리 | 놓치면 복구 불가 |
| `NORMAL` | 표시 없음 | 과태료·가산세 |
| `INFO` | 흐린 배지 | 실무 편의 |

> 🔴 **색만으로 구분하지 않습니다.** `00-23` §8.7이 *"색만으로는 안 보인다. 글자 배지 필수"*
> 라고 이미 정했고, 6070 시니어 페르소나(`00-09` §2.3)에서 색 대비만으로는 부족합니다.
> **⭐ 기호 + 글자 + 테두리 3중으로 겹칩니다.**

### 5.2 🔴 "되돌릴 수 없음"의 뜻이 항목마다 다릅니다

**같은 CRITICAL인데 되돌릴 수 없는 이유가 다릅니다. 뭉뚱그리면 경고가 무뎌집니다.**

| 유형 | 항목 | 한 줄 설명 |
| :--- | :--- | :--- |
| **기한이 지나면 권리가 사라짐** | 상속포기·한정승인 | *"지나면 빚을 그대로 물려받습니다"* |
| **물리적으로 되돌릴 수 없음** | 화장 24시간 제한 | *"화장 후에는 부검·재확인이 불가능합니다"* |
| **이걸 안 하면 다른 판단을 못 함** | 안심상속·재산 조사 | *"이걸 해야 3개월 안에 결정할 수 있습니다"* |
| **놓친 사람의 구제 경로** | 특별한정승인 | *"이미 늦었더라도 길이 있을 수 있습니다"* |

> 🟡 **배지 옆에 이 한 줄을 같이 띄웁니다.** *"되돌릴 수 없음"* 만으로는 유족이
> **무엇이 되돌릴 수 없는지** 모릅니다.

## 🔎 6. 🔴 추가 조사 — 누락 7건

### 6.1 🔴🔴 **후순위 상속인** — 이 도메인에서 가장 큰 구멍

**현재 23항목 어디에도 이 개념이 없습니다.**

> **상속포기는 그 사람만 빠지는 것이지 빚이 사라지는 것이 아닙니다.**
> 선순위가 포기하면 **다음 순위로 넘어갑니다** — 자녀가 포기하면 손자녀, 그다음 고인의 부모,
> 그다음 형제자매 순으로. **가족 전원이 포기해야 끝납니다.**

| 왜 위험한가 | |
| :--- | :--- |
| 🔴 **자녀만 포기하고 끝난 줄 안다** | 실제로는 **미성년 손자녀**에게 채무가 넘어갑니다 |
| 🔴 **다음 순위는 통보를 못 받는다** | 자기가 상속인이 된 사실을 모른 채 3개월이 갑니다 |
| 🔴 **미성년자는 혼자 포기할 수 없다** | 법정대리인이 해야 하고, 이해상반이면 **특별대리인 선임**이 필요할 수 있습니다 |

> 🟡 **권고: 항목 추가가 아니라 §2.3 블록 안의 경고로 넣습니다.**
> *"상속을 포기하시면 다음 순위 가족에게 넘어갑니다. 누구까지 포기해야 하는지 확인하세요."*
> + 02 상담 연결. **이어봄이 순위를 판정해서는 안 됩니다**(`07-01` §4.3).
> 🔴 **법령·판례 대조 필요**(민법 §1000·§1001·§1043 계열로 파악하나 **조문 확정은 검수 대상**).

### 6.2 🔴🔴 **단순승인으로 간주되는 행위** — "하지 말 것"이 없습니다

**현재 체크리스트는 전부 "하세요"입니다. "하지 마세요"가 한 줄도 없습니다.**

> 상속인이 상속재산을 처분하면 **3개월을 기다릴 것도 없이 단순승인한 것으로 간주**되어
> 그 순간 채무 상속이 확정됩니다(민법 §1026 계열 — 🔴 **조문 확정은 검수 대상**).

| 유족이 실제로 하는 일 | 위험 |
| :--- | :--- |
| 🔴 **고인 통장에서 장례비를 인출** | **가장 흔합니다.** 통상적 장례비는 처분행위로 보지 않는 경향이나 **금액·범위에 다툼**이 있습니다 |
| 고인 자동차를 팔거나 폐차 | 처분행위 |
| 고인 명의 부동산 처분 | 처분행위 |
| 고인 채권을 추심해 수령 | 처분행위 |

> 🔴 **이게 이 도메인 최악의 시나리오입니다** — 유족이 **선의로, 급해서, 아무것도 모르고**
> 장례비를 빼는 순간 빚 상속이 확정될 수 있습니다. 그리고 **이어봄은 장례식장을 연결하는
> 서비스**라 유족이 정확히 그 순간에 우리 화면에 있습니다.
> 🟡 **권고: §2.3 최상단에 "결정 전에는 고인 재산에 손대지 마세요" 경고 블록.**
> 🔴 **금액 기준·판례 범위를 우리가 말하지 않습니다** — *"장례비도 다툼이 될 수 있으니
> 상담하세요"* 까지만. `07-01` §4.3의 경계선을 넘지 않습니다.

### 6.3 🟡 **상속포기 기간 연장 청구** — 3개월이 늘어날 수 있다는 사실

3개월이 부족하면 **가정법원에 기간 연장을 청구할 수 있습니다**(민법 §1019① 단서 계열 —
🔴 **조문·요건 확정은 검수 대상**). 재산 조사가 안 끝난 유족에게 실질적인 선택지인데
**현재 목록에 없습니다.**

> 🟡 §2.3에 항목으로 추가 권고. **특별한정승인(§2.3-11)과 짝**입니다 — 하나는 *"기한 전에
> 늘리는 길"*, 하나는 *"기한 후의 구제"* 입니다.

### 6.4 🟡 **받을 수 있는 돈** — 목록이 "내야 할 것"에 치우쳐 있습니다

현재 23항목 중 **유족이 돈을 받는 항목은 3건**(장제비·유족연금·보험금)뿐이고,
나머지는 신고·납부입니다. **놓치면 손해인 지원금이 빠져 있습니다.**

| 후보 | 대상 | 비고 |
| :--- | :--- | :--- |
| **산재 유족급여·장의비** | 업무상 재해 사망 | 🔴 근로복지공단. 청구 시효 별도 |
| **기초생활수급자 장제급여** | 수급 가구 | 지자체 |
| **의료급여 장제급여** | 의료급여 수급권자 | |
| **국가유공자 장제비** | 보훈 대상 | 🔴 해당자만 |
| **고인의 미지급 임금·퇴직금** | 재직 중 사망 | 사업주 청구 |

> 🟡 **전부 "해당자만"이라 §4 개인화 분기가 필요합니다.** 무조건 노출하면 22항목이 30항목이
> 되어 `07-02` §4가 경고한 *"가장 중요한 항목이 소음에 묻힌다"* 가 됩니다.
> 🟡 **권고: "혹시 해당되시나요?" 접이식 블록 하나**로 묶고 기본은 접어 둡니다.
> 🔴 **금액·요건은 적지 않습니다** — 제도가 자주 바뀌고 틀리면 `07-01` §1.4의 대가를 치릅니다.
> 링크와 소관 기관만 답니다.

### 6.5 🟡 **사망신고 전에 확인할 것** — 순서 함정

**사망신고를 하면 되돌릴 수 없는 변화가 생깁니다.** 그런데 현재 목록은 사망신고를
*"1개월 안에 하세요"* 라고만 합니다.

| 사망신고 후 | |
| :--- | :--- |
| 고인 명의 계좌·카드 | 지급정지·자동이체 실패 가능 |
| 고인 명의 증명서 발급 | 제한될 수 있음 |

> 🟡 **권고: 사망신고 항목에 *"먼저 확인하세요"* 하위 안내를 답니다.**
> 🔴 **"사망신고를 미루세요"로 읽히면 절대 안 됩니다** — 법정 의무이고 과태료 대상입니다.
> 문구는 **"신고 전에 챙길 것"** 이지 **"신고를 늦추라"** 가 아닙니다. 이 선을 넘으면
> 이어봄이 위법을 권한 것이 됩니다.

### 6.6 🟡 **임대차 승계** — 살 곳의 문제

고인이 **임차인**이었다면 유족의 거주가 걸립니다(주택임대차보호법 §9 계열 — 🔴 **확인 필요**).
고인이 **임대인**이었다면 보증금 반환 의무가 상속됩니다.

> 🟡 §2.5(명의·자산)에 항목 추가 권고. **§6.4보다 우선순위가 높습니다** — 돈보다 거주가 급합니다.

### 6.7 🔴 `07-02` §7 미결 2건 — 조사 결과

| # | 쟁점 | 조사 결과 |
| :---: | :--- | :--- |
| 2 | **부동산 상속등기 의무화 여부** | 🔴 **의무화됐다고 단정하지 마십시오.** 확인한 범위에서는 **상속등기 자체에 법정 기한 의무는 없고**, 실질 기한은 취득세 6개월입니다(현행 §2.5-17 표기가 맞습니다). **다만 제도 변경 논의가 있어 `lastVerifiedAt` 관리 대상**입니다 |

> 대조 + 02 전문가 검수**를 거쳐야 `verified: true`가 됩니다. 이 문서는 **후보와 근거 방향**까지입니다.
