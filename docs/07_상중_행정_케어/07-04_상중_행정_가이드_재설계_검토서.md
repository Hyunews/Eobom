> (기일 데이터 없는 경우)."*

| 안 | 내용 | 판정 |
| :--- | :--- | :---: |
| A | `Deceased` 확정을 기다린다 | ❌ 무기한 대기 |
| B | 날짜 하나만 화면에서 입력받아 브라우저에 보관 | ❌ **2026-08-28 기각** |
| C | 서버에 사망일만 저장하는 모델 신설 | ❌ `Deceased`와 충돌 |

**🟡 기각된 B안이 왜 기각될 만했는지 — 뒤늦게 보이는 것들**

#### 3.1-1 🔵 **`Deceased`로 사망일이 확보된 회원은 예외입니다**

> **개발자 확정**: *"기일 데이터가 나중에 `Deceased`로 확보된 회원의 경우, 그에 맞게 판단할

**즉 사망일은 *"받는 것"* 이 아니라 *"이미 있으면 쓰는 것"* 이 됩니다.** 이 구분이 D안의 핵심입니다.

| 상태 | 화면 |
| :--- | :--- |

| 🆕 **`Deceased.deathDate`가 있는 회원** | 구간 라벨 **+ 계산된 실제 날짜**(*"2026년 11월 30일까지"*) |

> 만들면 안 된다"* 는 **날짜를 아는 경우에 그대로 유효**하고, 모르는 경우에는 **애초에 D+N을
> 보여주지 않으므로**(구간 라벨은 상대 표현) 환산을 요구하지도 않습니다.
> 🔴 **그래서 구간 라벨에 `D+30`·`D+90` 같은 표기를 쓰지 않습니다**(§4.1-1). 쓰는 순간
> *"기준일 없이 D+N을 던지는"* — `07-01` §1.3이 폐기한 바로 그 상태로 돌아갑니다.
> 🟡 **선행조건 없음** — `Memorial.deceasedDeathDate`는 이미 있고(`schema.prisma:465`),
> `Deceased.deathDate`도 이미 있습니다(`:545`). **없으면 안 보여주면 되는 구조**라
> `00-12` 확정을 기다리지 않습니다.

### 3.2 🔴 날짜를 모르는 유족이 **기본값**입니다

`care-guide`는 `00-26` §4.2-1이 정한 **유일한 무로그인 화면**이고, 진입 장벽을 세우면

> ✅ **날짜 없는 상태가 예외가 아니라 정상**입니다. 구간 이름만으로 그룹핑하고

> (`06-04` §2.2가 지적한 패턴).

### 3.3 🔴 "안 날" 문제는 그대로 남습니다

`07-01` §4.3 — **상속포기 3개월의 기준일은 사망일이 아니라 "상속개시 있음을 안 날"** 이고

*"기준일이 다를 수 있습니다"* 를 병기**하고 02 상담으로 연결합니다. **이건 §4.3 그대로입니다.**

> 🔵 **D안에서 이 위험이 오히려 줄었습니다.** 날짜를 받지 않으면 *"11월 30일까지"* 라는

### 3.4 🆕 **체크 상태 — 회원은 유지, 비회원은 유실 허용**(2026-08-28 확정)

## ⭐ 5. 강조 체계 — **"되돌릴 수 없음"을 항목마다**

### 5.1 🟡 3단 표기

| severity | 표시 | 뜻 |
| :--- | :--- | :--- |
| **`CRITICAL`** | ⭐ + **"되돌릴 수 없음"** 글자 배지 + 좌측 굵은 테두리 | 놓치면 복구 불가 |
| `NORMAL` | 표시 없음 | 과태료·가산세 |
| `INFO` | 흐린 배지 | 실무 편의 |

> 🔴 **색만으로 구분하지 않습니다.** `00-23` §8.7이 *"색만으로는 안 보인다. 글자 배지 필수"*
> 라고 이미 정했고, 6070 시니어 페르소나(`00-09` §2.3)에서 색 대비만으로는 부족합니다.
> **⭐ 기호 + 글자 + 테두리 3중으로 겹칩니다.**

### 5.2 🔴 "되돌릴 수 없음"의 뜻이 항목마다 다릅니다

**같은 CRITICAL인데 되돌릴 수 없는 이유가 다릅니다. 뭉뚱그리면 경고가 무뎌집니다.**

| 유형 | 항목 | 한 줄 설명 |
| :--- | :--- | :--- |
| **기한이 지나면 권리가 사라짐** | 상속포기·한정승인 | *"지나면 빚을 그대로 물려받습니다"* |
| **물리적으로 되돌릴 수 없음** | 화장 24시간 제한 | *"화장 후에는 부검·재확인이 불가능합니다"* |
| **이걸 안 하면 다른 판단을 못 함** | 안심상속·재산 조사 | *"이걸 해야 3개월 안에 결정할 수 있습니다"* |
| **놓친 사람의 구제 경로** | 특별한정승인 | *"이미 늦었더라도 길이 있을 수 있습니다"* |

> 🟡 **배지 옆에 이 한 줄을 같이 띄웁니다.** *"되돌릴 수 없음"* 만으로는 유족이
> **무엇이 되돌릴 수 없는지** 모릅니다.
