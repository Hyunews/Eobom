2. 외부 웹 서비스 사례

2.1 Diátaxis 프레임워크

Django, Cloudflare, Gatsby가 채택. 문서를 사용자 의도 기준으로 4종류만 인정:

종류언제 읽나성격이어봄 대응
Tutorial처음 배울 때학습 · 따라하기온보딩 가이드
How-to작업할 때문제 해결 · 레시피도메인별 구현 가이드
Reference사양 찾을 때사실 기반 · 정확API/DB/화면 명세
Explanation이유가 궁금할 때맥락 · 판단근거결정 기록(ADR)
핵심 규칙: 4종류를 섞지 않는다. 지금 이어봄은 하나의 문서 안에 Tutorial + Reference + Explanation이 전부 들어가 있습니다.

2.2 Stripe — 업계 최고 문서 구조

docs/ ├── Getting Started ← "10분 안에 결제 붙이기" (Tutorial) ├── API Reference ← 엔드포인트 사전 (Reference) ├── Integration Guides ← "구독 결제 구현하기" (How-to) ├── Changelog ← 무엇이 바뀌었나 (시간축) └── Building Blocks ← "왜 이렇게 설계했나" (Explanation)
