- 🔵 **같은 날 재판단 2회 — 최종: 채널 개설 + 1:1 채팅까지, 상담톡 API 미도입.**
  개발자가 *"카카오 상담톡은 협력사가 API를 따로 관리하고 유료"* 임을 확인하고 일단
  *"버튼만 만들고 보류"* 로 정했다가, §5.1-1의 구분(**유료는 상담톡 API뿐, 채널 1:1 채팅은
  무료**)을 보고 *"채널 개설 / 1:1 채팅 응대까지만 우선 해보자. 내가 채널 개설 해올게"* 로
  범위를 확정했다. **채널 개설은 사장님이 진행.**
  🔵 **유료인 것은 「상담톡(API 연동)」이고 「채널 1:1 채팅 응대」는 무료**(관리자센터 웹/앱에서
  사람이 직접 답변)라는 구분을 §5.1-1로 신설했다 — 이 구분이 없으면 **무료로 할 수 있는 것까지
  미루게 된다.** ⚠️ 카카오 요금·정책은 자주 바뀌므로 단정하지 않고 *"관리자센터에서 직접
  확인"* 으로 남김(`AGENTS.md` §6).
  🔴 **다만 "버튼만 만들기"는 성립하지 않는다** — URL은 채널을 개설해야 나오고, URL 없는 버튼은
  `1588-0000`과 같은 사고다. **순서를 "개설 → 구현"으로 고정**하고 §5.4-2-1을 신설했다.
  🔵 **개설 후 가져올 값 3개**: ①채널 홈 URL(`http://pf.kakao.com/_XXXXX`) ②검색용 아이디
  (`@이어봄`) ③응답 가능 시간 — 🔴 **관리자센터 설정값과 화면 문구를 같은 값으로**(갈리면
  관리자센터는 부재중인데 화면은 상담중이 된다).
  ✅ **값이 오기 전까지 `Footer`는 손대지 않는다** — 버튼이 없으면 `Footer.tsx:123`의
  *"전화로 안내해드립니다"* 가 **여전히 참**이다. §5.4-1 문구 수정과 버튼 추가는 **한 커밋**.
  🔴 비용이 풀렸다고 제약이 다 풀린 건 아니다 — `00-14` 2-4의 **답할 사람** 문제가 채팅으로
  옮겨올 뿐. 🟡 다만 채팅은 **비동기 응답이 가능**해 전화처럼 *"지금 못 받으면 놓치는"*
  구조가 아니라 덜 아프다. 응답 시간을 정직하게 적는 것이 그 전제.
- ✅ **같은 날 채널 개설 완료(사장님) — `07-04` §8-5 닫힘.**
  채팅 `https://pf.kakao.com/_LVxdxaX/chat` · **평일 09:00~17:00** · 연령 **전 연령**.
  🔴 **연령은 「전 연령」이 맞다** — 카카오 개설 화면의 *"성인인증 채널"* 안내는 모든 개설자에게
  나가는 일반 문구이고, 장례·행정·추모는 청소년유해매체물이 아니다. **더 중요한 건 반대쪽**:
  성인인증을 걸면 6070 시니어에게 본인인증이 장벽이 되고, **미성년 유족이 막힌다** —
  `07-04` §6.1(후순위 상속인)·§6.2(단순승인 간주)가 *"모르고 있다가 당하는"* 유형이라
  **미성년 상속인이 위험이 가장 큰 집단**이다.
  🔴 **받아온 URL이 `http://`라 `https://`로 바꿔 기록했다** — 화면이 HTTPS라 평문 링크를
  남길 이유가 없다. `pf.kakao.com`은 HTTPS 지원.
  ✅ **버튼은 `/chat` 하나만** — 채널 홈은 "친구 추가"를 먼저 요구해 단계가 하나 늘고,
  6070에게 선택지는 배려가 아니라 장벽이다(`00-09` §2.3).
  🔴 **버튼 라벨은 "상담"이 아니라 "문의"** — 02(전문가 상담)와 혼동되면 이어봄이 법률·세무

  🟡 확인 2건(비차단): 점심시간 제외 여부 · 공휴일 표기. 안 정하면 받은 값 그대로 간다.
  🔵 **추가 확정 — 유선은 소비자 창구가 아니다**(*"유선 문의는 소비자 아닌 우리 협력 업체들과
  가능하도록"*). 전화 설명문을 **`사업장·전문가 문의`** 로. **일반 이용자=카톡 / 사업자=전화**로
  성격이 갈린다. 🔴 **다만 070은 `00-19` 제12조 정보주체 문의 창구 번호**라, 화면이 사업자용
  이라고만 부르면 개인정보 열람·삭제 요구자가 안 걸 수 있다. ✅ 위반은 아니다 — 필수 기재사항은

  ✅ **같은 대화에서 해소** — 개발자가 *"사업장 전문가 및 개인정보 문의로 문구를 할까?"* 로
  제안. 최종 문구는 **`사업장·전문가 문의 · 개인정보 열람·삭제 요청`**. 🟡 *"문의"* 와
  *"요청"* 을 가른 이유 — 개인정보 열람·정정·삭제·처리정지는 **법이 보장한 권리 행사**
  (법 §35~37)라 "문의"로 묶으면 성격이 흐려지고, *"열람·삭제"* 라는 구체어가 있어야 정보주체가
  자기 것임을 알아본다. 🔴 **문구와 무관하게 전화가 오면 응대해야 한다** — 돌려보내면
