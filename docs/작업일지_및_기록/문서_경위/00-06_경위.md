## 📎 부록: 경위

### A. 2026-08-11 전면 갱신

기존 문서는 "15개 화면"이라 적어놓고 8개만 나열했고, 그중 상속세 계산기 위치가 실제와 달랐으며, 파트너·운영자 화면 3개가 통째로 누락돼 있었습니다. 실제 구현을 기준으로 인벤토리를 다시 세웠습니다.

### B. §1 상태 칸·ID 이력

- 2026-10-12 정리 전 상태 칸: SCR-002·006·013 *"🔶 프론트 목업"*, SCR-003 *"디지털 계정 정리 · 🔶 프론트 목업"*, SCR-004 *"실데이터 1,552건"*(숫자는 손으로 쓰면 낡아 뺌 — 시설 수는 DB 조회값을 인용).
- `SCR-005`는 원래 `DigitalEstatePage.tsx` 안에 있었으나 → `CounselingPage`(SCR-007) 인라인 → **`TaxSimulatorModal` 분리**로 두 번 이동(2026-08-11). 페이지 지분을 과하게 차지해 버튼+모달로 분리.
- **`SCR-013`·`SCR-014`·`SCR-015`(2026-08-19 신설)** — 신규 개발이 아니라 기존 화면의 분리(`00-26` §7.1, `walkthrough` (39)). `SCR-013`은 `SCR-006` 안의 **모바일 부고장 폼**을 떼어낸 것(→ `SCR-006` 이름에서 *"부고장"* 제거). `SCR-014`·`SCR-015`는 `SCR-003`(`/digital-estate`)의 서브탭 `physical`·`memorial`을 떼어낸 것 — `00-14` §2.3 *"한 페이지가 03·04·05를 뭉치고 있음"* 해소.
- `SCR-015`는 처음엔 헌화·방명록·앨범의 화면 구성을 보여주는 **예시 페이지**였다가 09-07부터 실제 관리 화면. `SCR-002-B`·`SCR-015`는 09-22 표기 정정.
- **`SCR-016`·`SCR-017`(2026-08-27 신설 → 2026-09-28 폐지)** — `00-23` §8.6-1 #1이 요구한 등재. 원래 홈 박스①②를 누르면 뜨던 `BoxDetailOverlay`(풀스크린 오버레이)였는데 08-25 개발자 지시로 일반 페이지 `DomainOverviewPage.tsx`(`/prep`·`/bereaved`, 문구 `home/domainSlides.tsx`의 `box1*`/`box2*`)로 전환되며 화면 ID를 받았습니다. 한 컴포넌트가 `mode` prop으로 두 ID를 담당했고, 직접 진입 시 사이드바 모드가 바뀌는 첫 사례였습니다(`00-23` §8.6-1·§8.6-2). `00-40` §3.3 C6(09-28)로 페이지가 삭제되고 두 경로는 `HomePage landingMode`로 돌아갔습니다.
- `SCR-011`의 블로커였던 *"`Deceased` 미확정"* 은 `Deceased` 모델 도입으로 화면 블로커에서 빠졌습니다(프리필 문제는 `backlog` ③).

### F. §8 `SCR-018` — 초판(09-03)과 바뀐 것

초판 문제 제기: 헤더 `추모관`은 `goToMemorialEntry`가 `navigate('/?entry=box3')` 하나뿐이라 **"받은 링크를 입력하세요" 칸으로만** 보냈고, 링크를 만든 사람은 자기가 뭘 만들었는지 볼 수 없었습니다. `07-03` §9 **9-2**는 이 화면을 *"부고장이 2개 이상이 될 때"* 로 미뤄뒀습니다.

| | 초판(09-03) | 2026-09-07 구현(wt134·135·142·144) |
| :--- | :--- | :--- |
| 경로 | `/my-obituaries` | **`/my-obituaries-memorials`** |
| 진입 | 헤더 `추모관` 메뉴 | 마이페이지 "내 부고장" 통계 칸 — 유일한 통로(헤더 메뉴 삭제) |
| 구성 | ① 부고장 목록 ② **받은 링크 입력** | ① 부고장 목록 ② **내 추모관 목록**(읽기 전용) — 좌우 2단 |

- **왜 바뀌었나** — `06-05` wt135가 **부고장과 추모관을 완전히 분리**하면서 추모관이 독립 자원이 됐습니다. 그래서 ②단이 받은 링크 입력에서 내 추모관 목록으로 바뀌었습니다.
- **§8.1 초판 표**: ① 내가 만든 부고장 목록(고인명·사망일·상태·개설일 / 부고장·추모관 링크 열기+공유 / `관리`는 `SCR-013`) · ② ~~받은 링크 입력~~(홈 `box3`과 같은 입력) → 폐기(wt142), 홈 `box3`이 그 역할을 계속.
- **§8.2 헤더 연결(폐기 09-07)**: 초판은 `Header.tsx` `goToMemorialEntry`의 목적지를 이 페이지로 바꾸고(wt134) 라벨도 `내 부고장`으로 고쳤는데(wt142), 09-07 개발자 지시로 헤더 메뉴 자체를 없앴습니다.
- **§8.4 초판의 "하지 않는 것"**: 부고장 편집·종료(→ `SCR-013`, 지금도 같음) · 추모관 개설 버튼(당시 `05-01` §6.2가 `00-12` §6 모드 UX 확정 대기 — 이후 `SCR-015`에 생김) · 추모관 목록 단(09-07 뒤집힘 — 초판 전제 *"부고장 1건에 추모관 1개가 딸린다"* 가 wt135로 사라져, 부고장 없는 추모관이 어디에도 안 보이게 되므로 ②단으로 생김).
