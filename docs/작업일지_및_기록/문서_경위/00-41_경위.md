## 🗣️ 2. 지시 원문 (2026-09-30, 개발자)

> *"반나절 안에 처리해야 한다(유족입장에서 급함) / 운영자 계정을 통한 대시보드 확인."*

- 🔄 **2026-10-02 개발자 변경② — 공휴일 목록을 코드에 두지 않고, 유족 화면에 완료 예정 시각(`dueAt`)을 표시하지 않는다.** 6시간은 **내부 처리 기준**이며 유족 화면에는 운영시간과 처리 기준 문구(§8.1)만 둔다. 공휴일은 운영자가 판단한다. `dueAt`·`targetAt`은 운영자 대시보드 정렬·지연 색에만 쓰고 평일만 센다. 코드는 `[Sonnet]` 반영 대상.
- 🔄 **2026-10-02 개발자 변경 — 대외 약속 12시간 → 운영시간 기준 6시간.** 아래 본문의 값은 6시간으로 고쳤고, 이 절의 지시 원문(12시간)은 기록으로 둔다. 코드(`dueAt` 계산·안내 문구)는 `[Sonnet]` 반영 대상.

  > *"12시간보다 더 빠르게 실제론 진행될거임. 1시간 이내. 하지만 대외적으론 그렇게 나가는거지"*
