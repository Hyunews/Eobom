### §4.4 머리 — 지시 원문

> 원문: *"유언mp3 → 유언장 생성 : 아마 **TTS** 이용해야할 듯. 구현해야함."*

#### 4.4-1 🔴 먼저 용어를 바로잡습니다 — **TTS가 아니라 STT입니다**

| | 무엇 | 방향 |
| :--- | :--- | :--- |
| **STT**(Speech-to-Text) | 말 → 글 | **mp3 → 유언장. 지시하신 방향은 이쪽입니다** |
| **TTS**(Text-to-Speech) | 글 → 말 | 유언장 → 낭독 음성 |

🔴 **어느 쪽을 원하신 것인지 확정이 필요합니다.** *"mp3 → 유언장 생성"* 은 STT인데 **TTS라고
적혀 있어**, 혹시 **반대 방향**(작성한 글을 음성으로 읽어주기)을 의도하셨을 수 있습니다.
**두 기능은 목적·비용·법적 쟁점이 전부 다릅니다**(§4.4-4).

> 2026-08-25 개발자 확정 — **STT**(`06-04` §6.4 머리). 이후 음성 업체 선정(CLOVA Speech, 08-26)까지 STT로 진행. TTS는 §4.4-3 ③(별건)으로만 남음 → 본문 §7 #6.

#### 4.4-4 🔴 구현 전에 걸리는 것 — **기술이 아니라 데이터입니다**

| # | 쟁점 | 상태 |
| :---: | :--- | :--- |
| **1** | **음성 파일을 어디에 저장하나** | 🔴 **현재 이미지가 로컬 디스크라 재배포 시 소실**됩니다(`context.md` · `systems.md` §5). 오브젝트 스토리지는 `00-11` 인프라 확정 대기 — **추모관 사진이 같은 이유로 오픈 금지 상태**입니다 |
| **2** | **외부 STT API로 보내면 `06-03`의 약속과 충돌합니다** | 🔴 *"운영자는 내용을 열람하지 않습니다"* 라고 해놓고 **유언 내용을 제3자 클라우드로 전송**하게 됩니다. 위탁 고지·국외이전(`00-19` 제7조·`00-17` §3.4) 대상이며 **처리방침 개정 없이는 불가** |
