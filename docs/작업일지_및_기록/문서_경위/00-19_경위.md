**실측(2026-08-18)**: `LoginModal.tsx`의 소셜 버튼 3개가 **곧바로 OAuth로 리다이렉트**하며,

**즉 위 문장은 지금 사실이 아닙니다.**

##### 🔴 방식: **자기신고(self-declaration). 생년월일을 받지 않습니다.**

| 후보 | 판정 |
| :--- | :--- |
| **🟡 가입 시점 자기신고 확인**(권고) | ✅ **수집 항목이 늘지 않습니다.** 실무 표준이며 구현이 가장 작습니다 |
| 생년월일 직접 입력 | ❌ **만 14세 미만을 막으려고 전 이용자의 생년월일을 수집**하게 됩니다 — **최소수집 원칙과 정면 충돌**하고 §3 수집 항목이 늘어납니다 |
| 소셜 제공자의 연령대 정보 수신 | ❌ **3사 중 일부만 제공**하고 **추가 동의라 거부 가능**해 정책으로 성립하지 않습니다. 게다가 이것도 수집입니다 |

> ✅ **"덜 걷는 쪽"이 정답인 드문 경우입니다** — 보호를 위해 정보를 더 걷는 설계는
