### 1. 처음 검토 요약과 결론 (2026-08)
처음 표는 Layer 2를 **`[조건부 준수 & 우회 가능]`**, 트랙 B를 **"행정동/검색어 기반 우회 기획 (신고 면제)"**으로 적었고, 수익 모델 칸은 *"유족 정보 무상 개방 + B2B 입점/리드 수수료"* 였습니다. 결론은 다음과 같았습니다.

> 공공데이터법상 상업적 영리 이용은 100% 승인되어 있으나, **실시간 GPS 기반 LBS 거리 정렬 기능은 위치정보법상 방송통신위원회(KCC) 사업자 신고 대상**입니다. 이에 대한 **행정 신고 절차(트랙 A)** 및 **행정동/검색어 선택 기반 우회 서비스 기획(트랙 B)**을 다원화하여 법적 리스크를 100% 제거합니다.

2026-09-10 트랙 A를 켜면서 *"우회"* 로 적었던 트랙 B가 폴백 정상 경로가 됐고, *"리스크 100% 제거"* 같은 단정은 뺐습니다. 당시 2.2 본문은 *"공공데이터포털 API 신청 시 신고필증 미첨부 시 반려"* 를 모든 데이터셋의 사정처럼 적었는데, 2026-09-09 실제 승인 결과로 그렇지 않음이 확인됐습니다.
