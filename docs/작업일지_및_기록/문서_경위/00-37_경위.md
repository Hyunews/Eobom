### 2.2 🔴 API는 있는데 화면이 없는 것 — 4건

| 엔드포인트 | 무엇 | 화면 |
| :--- | :--- | :---: |
| `GET /admin/memorials` · `PATCH /:id/review` · `PATCH /:id/guestbook/:gid/hide` | **추모관 신고 심사 · 방명록 숨김** | ❌ |
| `GET /admin/digital-platforms` · `POST` · `PATCH /:id` | **디지털 플랫폼 카탈로그 관리**(04 도메인 마스터 데이터) | ❌ |
| `GET /admin/consult-requests` | 상담 신청 전체 조회 | ❌ |
| `GET /admin/users/:id` | **회원 상세**(개인정보 열람) | ❌ |

> 🔴 **특히 추모관 신고 심사입니다.** 공개 추모관(`/m/:slug`)에 신고 버튼이 이미 붙어 있고
> (`MemorialLandingPage.tsx`), 신고가 들어오면 **처리할 화면이 없습니다.**
