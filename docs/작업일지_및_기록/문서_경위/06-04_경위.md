##### 🔴 Storage 설정이 §4.1 ③과 충돌합니다 — 구현 시 실측 확인 필요

> ✅ **해결됨 — 2026-08-26 실측 확인**(walkthrough, `[Sonnet]`):

> 콘솔이 도메인 생성 시 경로를 **필수 입력**으로 요구할 뿐, 실제로는 지나가지 않습니다.
> → **§4.1 ③ 위반 없음.** ③(KMS 키 권한)도 이 결과로 **무의미해졌습니다**(버킷을 안 쓰므로).
