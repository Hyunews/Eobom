## 🪝 5. `useIsMobile` 훅 명세

### 5.1 시그니처

```ts
// eobomDev/frontend/src/hooks/useIsMobile.ts
export function useIsMobile(maxWidth: number = 768): boolean;
```

| 항목 | 스펙 |
| :--- | :--- |
| **인자** | `maxWidth` — **모바일로 간주할 최대 폭(inclusive)**. 기본 **768** |
| **질의** | `window.matchMedia(\`(max-width: ${maxWidth}px)\`)` |
| **왜 inclusive 768인가** | `index.css`의 지배적 브레이크포인트가 `@media (max-width: 768px)`다. 여기에 맞춰야 **768px 정확히에서 JS와 CSS가 어긋나지 않는다** |
| **초기값** | 🔴 **lazy initializer로 즉시 평가**한다(`useState(() => mql.matches)`). `useEffect`에서 처음 계산하면 **데스크톱 뷰가 한 프레임 그려졌다 바뀐다** |
| **SSR** | 없다(Vite SPA). `typeof window` 가드는 넣지 않는다 — 죽은 코드다 |
| **구독** | `addEventListener('change', …)` + cleanup. 🟡 **`addListener` 폴백을 둔다** — 주 페르소나가 6070이라 구형 iOS Safari(≤13) 비중을 0으로 볼 수 없다 |
| **의존성** | `[maxWidth]`. 🔴 호출부는 **리터럴만** 넘긴다 — 계산식을 넘기면 매 렌더 재구독된다 |

### 5.2 🔴 기존 `matchMedia` 호출부 — 훅으로 통일하되 **값은 바꾸지 않는다**

> 🔄 **10-12 코드 대조** — 09-08 표의 `EntryBoxes`·`DomainOverviewPage`는 **삭제**됐고(홈 = `00-40`), `HomePage`는 `useIsMobile()`(768)을 씁니다. 지금 호출부:

| 위치 | 지금 | 비고 |
| :--- | :--- | :--- |
| `App` · `HomePage` · `EndingNotePage` · `FarewellMessagePage` · `ObituaryPage` · `FacilityPage` · `WillPhotoResult` · `Footer` | `useIsMobile()` / `useIsMobile(768)` | 기본 768 |
| `FacilityPage` | `useIsMobile(480)` | 사진 자리 숨김 — 화면별 이유가 있는 값 |
| `FamilySharedPage` | `matchMedia('(pointer: coarse)')` | 🔴 **폭이 아니라 입력 방식** 판정 — 훅으로 바꾸지 않는다 |
| `DigitalEstatePage` | `matchMedia('(min-width: 768px)')` 직접 | 🟡 훅을 안 거친 남은 1곳(값 768 = 훅과 1px 어긋남 — 767↔768 경계) |

> 🔴 **값을 768로 강제로 통일하지 않는다.** 각자 이유가 있는 값이면 그대로 두고, **통일하는 것은 API지 값이 아니다.**

### 5.3 🔴 함정 — **effect 클로저가 훅 값을 굳힌다** (2026-09-08 wt173에서 실제로 걸림)

훅은 **렌더 스냅샷**을 준다. 그 값을 **마운트 시 1회만 도는 `useEffect`** 안에서 읽으면
클로저에 캡처돼 **리사이즈 이후에도 옛 값이 남는다.** `matchMedia`를 직접 구독하던 코드에는
없던 함정이라, 훅으로 바꾸는 것만으로 조용히 회귀가 생긴다.

```tsx
// ❌ useEffect(..., [sections.length]) 안에서 isMobile을 직접 읽으면 값이 굳는다
// ✅ ref로 미러링하고 핸들러는 ref를 읽는다
const isMobile = useIsMobile(640);
const isMobileRef = useRef(isMobile);
useEffect(() => { isMobileRef.current = isMobile; }, [isMobile]);
```

- ✅ **`HomePage.tsx`가 이 방식으로 처리됐다**(wt173 편차) — **판정: 통과, 스펙갱신 불요.**
  동작은 기존과 동일하고 §5.2의 *"값은 그대로"* 취지도 지켰다.
- 🔴 **Phase 2~4에서 같은 함정이 재발한다.** 스크롤·휠·키보드 핸들러를 마운트 1회 effect로 다는
  화면(`HomePage`·`DomainOverviewPage`·모달류)에서 훅 값을 쓸 때는 **반드시 ref 미러링**한다.
- 🔵 **JSX 안에서 쓸 때는 문제없다** — 매 렌더 최신값이다. 함정은 **effect 클로저**뿐이다.

## 🧩 6. 적응형 뷰 분리 패턴

### 6.1 구조

```
pages/XxxPage.tsx  ← 라우트가 가리키는 곳. URL 그대로.
 ├── 데이터 로딩 · API 호출 · 상태(useState) · 핸들러 …… 🔴 여기 1벌만
 ├── const isMobile = useIsMobile();
 └── return isMobile ? <XxxMobileView {...vm} /> : <XxxDesktopView {...vm} />

components/<domain>/XxxDesktopView.tsx   ← 표현만. 상태 없음.
components/<domain>/XxxMobileView.tsx    ← 표현만. 상태 없음.
```

- **파일 위치**: `components/<domain>/` — `00-35` §4.1이 세운 관례(`components/endingNote/`·`facility/`·`home/`)를 따른다. **barrel(`index.ts`) 만들지 않는다.**
- **`vm`(뷰모델)**: 두 뷰가 **같은 props 타입**을 받는다. 타입은 `components/<domain>/types.ts`에 둔다.

### 6.2 🔴 지켜야 할 것 — 4개

09-18 구속력은 풀렸지만 **분리한 화면의 코드는 지금도 이 4개를 따릅니다**(코드 주석이 가리킴): ① 상태·입력값은 부모에만, 뷰는 controlled ② `fetch`·`useEffect`를 뷰에 두지 않는다 ③ 뷰 컴포넌트를 부모 함수 안에 정의하지 않는다(`00-35` §6.1) ④ 데스크톱 뷰는 기존 JSX를 옮긴다. 원문은 부록 경위 C.

### 6.4 ✅ 허용되는 가로 스크롤 — `00-29`의 "가로 스크롤 0"과 충돌하지 않는다

09-18 해제 — 칩 트랙의 가로 스크롤을 허용하는 3조건. 🔴 **문서(`body`) 가로 오버플로 금지는 지금도 유지**(360px). 원문은 부록 경위 C.

#### 6.4-1 🆕 **세 번째 유형 — 데스크톱 최소폭 하한 + `.main-wrapper` 스크롤 패널** (2026-09-09)

> 🔴 **사람이 직접 지시하고 `/facility` 실기동에서 확인한 확정 사항이다**(wt179). 이 절은 그것을
> 뒤늦게 옮겨 적는 기록이며 **판정 대상이 아니다.** 경위: 데스크톱에서 창을 좁히면 `.container`가
> 끝없이 줄어들며 폼·버튼 줄바꿈이 반복적으로 깨져 **수동 CSS 땜질이 계속 필요했다.**

> 🔄 **이 절은 `00-39` §5-0(09-28 사람 확정)이 대체했습니다** — 지금 기준은 반대입니다: **소비자 화면은 최소폭 없이 줄어들고**, 최소폭 1200px + 좌우 스크롤은 **운영자 화면에만** 둡니다.
> 10-12 코드: 소비자 쪽 `min-width: 1200px`는 이미 빠졌고 아래 스크롤 패널(`.main-wrapper`)만 남았습니다. 🔴 운영자 화면 쪽 1200px는 **아직 코드에 없습니다** → `00-39` §5-0 표지 · [Sonnet] 코드 일.

**769px 이상에서는 `.container`를 일정 폭 아래로 더 줄이지 않고, 넘치는 폭은 `.main-wrapper`가 가로 스크롤로 받는다.**

| | 값 (`index.css:299~340`) |
| :--- | :--- |
| 적용 구간 | `@media (min-width: 769px)` — 🔴 **모바일(≤768px) 규칙은 건드리지 않는다** |
