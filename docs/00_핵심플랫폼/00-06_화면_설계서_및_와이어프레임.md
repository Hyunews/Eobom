## 📌 6. 미할당 ID

미할당 번호는 **`SCR-022`부터**입니다. 신규 화면이 생기면 이 번호부터 순서대로 씁니다.

- **기존 ID를 재사용하거나 당겨쓰지 마십시오** — 폐지된 `SCR-016`·`SCR-017`도 마찬가지입니다. 도메인 문서들이 참조하고 있습니다.
- **`-B` 접미는 *같은 화면의 분리* 일 때만 씁니다**(예: `SCR-002-B`). 새 화면은 새 번호를 받습니다.
- `SCR-001~015`라는 옛 표기는 계획 단계의 예상 개수였을 뿐 실제로 정의된 적이 없습니다. 번호를 준 이력은 부록 경위 C.

## 🚪 7. 회원 유형 진입 동선 — **2026-08-14 개발자 확정**

> **이 절이 답하는 질문**: 처음 온 사람이 *"나는 어느 문으로 들어가야 하나"* 를 알 수 있는가.
> §1~3은 화면이 **존재하는지**를 적는 대장이고, 이 절은 그 화면에 **닿을 수 있는지**를 적습니다.
> 신규 화면 ID는 발생하지 않습니다 — 기존 SCR-001·SCR-008 사이의 **연결**만 다룹니다.

### 7.1 원칙 — 역할은 나누고, 모드는 나누지 않는다

| 구분 | 진입 시점에 나누는가 | 근거 |
| :--- | :---: | :--- |
| **역할** — *당신은 누구인가* (일반회원 / 사업자 / 전문가 / 운영자) | ⭕ **나눈다** | 인증 체계가 물리적으로 다릅니다. `User`(소셜) vs `Partner`·`Expert`(이메일+비번, 승인제) vs `Admin`(시드 생성) → `01-05` §3.1, `02-02` §1 |
| **모드** — *당신은 지금 어떤 상황인가* (생전 준비 / 유족) | ❌ **가입 때 묻지 않는다** | `00-12` §6.2가 **A안(계정 유형 분리 가입)을 기각**했습니다 — *"한 사람이 둘 다 필요합니다. 내 엔딩노트도 쓰고 아버지 상도 치릅니다."* 모드는 **화면에서 고릅니다**(홈 진입 + 헤더 모드 버튼, 정본 `00-26`) |

**이 경계를 문서에 박아두는 이유**: *"회원 유형을 나누자"* 는 말이 두 가지로 읽히기 때문입니다.
역할은 계정 체계로 나누고, 모드는 같은 계정 안에서 언제든 바꿉니다 — 모드를 가입 유형으로 만들면 한 사람이 계정을 둘 가져야 합니다.

### 7.3 진입 지점 스펙

| # | 위치 | 문구 | 이동 | 왜 여기인가 |
| :---: | :--- | :--- | :--- | :--- |
| ① | **`LoginModal` 하단** (데모 버튼 블록 **위**, 구분선 아래) | `장사시설 · 전문가 회원이신가요?` + `파트너 로그인 →` | `/partner` 이동 + 모달 닫기 | **오인이 실제로 발생하는 지점.** 사업자가 헤더 `로그인`을 누르는 건 자연스러운 오인입니다. ✅ 구현 |
| ② | ~~**`Footer`**~~ | — | — | 🔄 **삭제**(개발자 확정, 2026-08) — 파트너 진입은 ① 하나. 경위는 부록 B |
| ③ | **`Header`** | — | — | ❌ **하지 않습니다.** 상단 바에 파트너 링크를 넣으면 다수인 B2C 소비자가 **모든 화면에서** 자기와 무관한 항목을 봅니다. 파트너는 소수·반복 방문자라 상시 노출의 이득이 작습니다 |

* ①의 크기는 `0.9rem` 이상 · 밑줄 · `var(--primary-color)`. **13px은 허용하지 않습니다**.
* ①은 **데모 버튼 위**에 둡니다. 데모 블록은 개발용이라 오픈 시 제거될 것이고, 그때 실제 링크가 같이 사라지면 안 됩니다.

### 7.4 포털 쪽 크롬 분리

`/partner`·`/admin`에서는 **B2C 크롬을 렌더하지 않습니다**(`App.tsx` `isPortalRoute`).

| | `/` `/facility` … (B2C) | `/partner` `/admin` |
| :--- | :---: | :---: |
| `Header` (로그인 버튼 포함) | ⭕ | ❌ |
| `Sidebar`(모바일 드로어) · `Footer` | ⭕ | ❌ |

- **가입 유형 선택 화면은 따로 두지 않습니다** — `PartnerPortalPage`가 `AccountType = 'FACILITY' | 'EXPERT'` 탭으로 분기합니다. 앞단에 화면을 하나 더 두면 클릭만 늘어납니다.

### 8.2-1 진입 — **마이페이지 단일 진입** (2026-09-07 확정)

- **유일한 통로 = 마이페이지 통계 "내 부고장" 칸**(`MyPage.tsx`, 클릭 가능).
- 🔵 **왜 하나로 좁혔나** — 헤더에 `추모관` 메뉴가 있고 사이드바에도 `디지털 추모관`(→ `/memorial`)이
  있어, **같은 이름이 서로 다른 화면을 가리키는 혼란**이 있었습니다. 이름을 고치는 대신
  **진입점을 하나로 줄이는 쪽**을 택했습니다.
- 🔴 **홈 `box3`(받은 링크 입력)은 그대로 둡니다.** 비로그인 조문객에게는 **그게 유일한 입구**입니다.
- 🟡 **부작용 — 진입점이 하나면 그 하나가 막히면 화면 전체가 닫힙니다.** 마이페이지 통계 칸을 손볼 때 **이 링크를 떨어뜨리지 않도록** 합니다.
