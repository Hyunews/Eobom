## 🧭 3. 전역 레이아웃 · 내비게이션

### 3.1 ⚠️ 사이드바 호버 시 레이아웃 시프트

**진단**: 데스크톱에서 사이드바에 마우스가 닿으면 `width: 240px`로 확장되며 `.main-wrapper`의
`margin-left`가 **72px → 240px**로 함께 밀립니다. 마우스가 우연히 스칠 때마다 **본문 전체가
좌우로 덜컥거려** 시각적 피로를 줍니다.

**제안**: 본문을 밀어내는 대신 **고정 슬림 아이콘 레일(72px)을 유지**하고, 호버 시
**플로팅 오버레이 드로어** 또는 **툴팁 팝오버**로 메뉴명을 노출합니다.

### 3.2 📱 모바일 하단 탭 바 권고

**진단**: 모바일(< 480px)에서 좌측 56px 사이드바가 상시 자리를 차지해, **375px 화면에서 본문
가로 폭이 319px**로 좁아집니다.

**제안**: 모바일 폭(< 768px)에서 사이드바를 `display: none`으로 숨기고 **하단 고정 탭 바**
(홈 · 장사시설 · 전문가 · 상중케어 · 전체메뉴)를 제공합니다. **6070 시니어가 한 손 엄지로
조작하기 가장 편안한 모바일 UI 표준**입니다.

> ⚠️ `00-26`(모드별 네비게이션 개편)과 **충돌 검토 필요** — 모드 드롭다운이 하단 탭 바와 어떻게
> 공존할지 정해야 합니다.

## 🔍 5. 타이포그래피 · 시니어 접근성

### 5.1 🔴 텍스트 명도 대비 — **가장 실질적인 항목**

**진단**: 보조 설명·날짜·힌트에 쓰이는 연한 그레이(`#94A3B8`, `#9CA3AF`)가 웜 크림 배경
(`#FBF9F5`) 위에서 **대비율 약 3.2:1 ~ 3.8:1**입니다. 시니어의 노안·시력 저하 시 흐릿합니다.

| 용도 | 현재 | 보정 | 대비율 |
| :--- | :--- | :--- | :--- |
| 보조 텍스트 | `#94A3B8` · `#9CA3AF` | **`#64748B`** | 4.8:1 — WCAG **AA** 통과 |
| 중요 안내 문구 | 〃 | **`#334155`** | 7.5:1 — WCAG **AAA** 통과 |

> 🟡 **이 항목을 최우선으로 권합니다.** 토큰 치환만으로 끝나고, `00-09`가 이미 *"시니어 접근성
> 토큰"* 을 규범으로 세워둔 것과 정확히 같은 방향입니다.

### 5.2 최소 터치 타겟 · 클릭 피드백

`index.css`의 `--min-touch-target: 56px` 원칙은 **이미 잘 설계돼 있습니다.**
여기에 `.btn`·`.card` 공통 클래스에 `:active { transform: scale(0.97); }` 를 더하면,
**손떨림이 있는 시니어도 버튼이 눌렸음을 즉시 인지**합니다.
