## 🔍 5. 타이포그래피 · 시니어 접근성

### 5.1 🔴 텍스트 명도 대비 — **가장 실질적인 항목**

**진단**: 보조 설명·날짜·힌트에 쓰이는 연한 그레이(`#94A3B8`, `#9CA3AF`)가 웜 크림 배경
(`#FBF9F5`) 위에서 **대비율 약 3.2:1 ~ 3.8:1**입니다. 시니어의 노안·시력 저하 시 흐릿합니다.

| 용도 | 현재 | 보정 | 대비율 |
| :--- | :--- | :--- | :--- |
| 보조 텍스트 | `#94A3B8` · `#9CA3AF` | **`#64748B`** | 4.8:1 — WCAG **AA** 통과 |
| 중요 안내 문구 | 〃 | **`#334155`** | 7.5:1 — WCAG **AAA** 통과 |

> 🟡 **이 항목을 최우선으로 권합니다.** 토큰 치환만으로 끝나고, `00-09`가 이미 *"시니어 접근성
> 토큰"* 을 규범으로 세워둔 것과 정확히 같은 방향입니다.
>
> 🔄 **지금(10-12 코드 대조)**: 보조 텍스트 토큰 `--text-muted`는 **`#6C7A89`로 바뀌었습니다**(`index.css`). 다만 `#94A3B8`·`#9CA3AF` 직접 지정이 **7개 파일 8곳**에 남아 있습니다(`index.css` 2 · `design-v2.css` · `Badge` · `EndingNotePage` · `ObituaryPage` · `KakaoMapModal` · `HomeMobile`) — `Badge`의 "준비 중" 글자색은 `00-23` §8.3 규격이라 함께 정할 일입니다.

### 5.2 최소 터치 타겟 · 클릭 피드백

`index.css`의 `--min-touch-target: 56px` 원칙은 **이미 잘 설계돼 있습니다.**
여기에 `.btn`·`.card` 공통 클래스에 `:active { transform: scale(0.97); }` 를 더하면,
**손떨림이 있는 시니어도 버튼이 눌렸음을 즉시 인지**합니다.

> 🔄 **지금(10-12 코드 대조)**: `--min-touch-target`은 56px 그대로지만, 터치 기준의 정본은 **44px**로 정해졌습니다(`00-40` M-8 · `00-38`). `:active` 눌림 표시는 모바일 홈 메뉴(`.home-m-menu-item`)에만 있고 `.btn`·`.card` 공통에는 없습니다 — 채택 여부는 §4와 같이 결정 대기.
