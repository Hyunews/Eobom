# 🛠️ 08. 구현 난관 및 기술 솔루션 (Technical Solutions)

> **문서 목적**: 개발 과정에서 발생하는 주요 난제(소셜 계정 중복, LBS 사업자 신고 장벽, 256-bit AES 암호화 금고, 포트 충돌 회피)와 그에 대한 해법을 기술합니다.

---

## 💡 주요 기술 난제 및 솔루션

1. **소셜 로그인 이메일 중복 시 유니크 제약 충돌**:
   * **해법**: `CREATE_NEW` 선택 시 `User.email`을 `null`로 처리하고 `SocialAccount.email`에 개별 보존.
2. **정부 공공 API 신청 시 'LBS 사업자 신고' 장벽**:
   * **해법**: 행정 절차 대신 **카카오 로컬 REST API (`query=장례식장`) + CSV 파싱 시딩** 기법으로 LBS 신고 없이 전국 1,100개 시설 데이터 100% 확보.
3. **PostgreSQL 포트 충돌 (기본 5432 포트)**:
   * **해법**: Docker 컨테이너 포트를 `5433`으로 우회 매핑하여 타 프로젝트 DB와의 충돌 완전 예방.
