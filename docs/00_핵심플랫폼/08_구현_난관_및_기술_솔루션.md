# 🛠️ 08. 구현 난관 및 기술 솔루션 (Technical Solutions)

> **문서 목적**: 개발 과정에서 발생하는 주요 난제(소셜 계정 중복, LBS 사업자 신고 장벽, 로컬 HTTPS/Geolocation 제한, 256-bit AES 암호화 금고 등)와 그에 대한 해법을 기술합니다.

## 💡 주요 기술 난제 및 솔루션

### 1. 소셜 로그인 이메일 중복 시 유니크 제약 충돌
* **문제**: 동일 이메일로 다른 소셜 계정(카카오/네이버/구글) 가입 시 DB 이메일 유니크 제약 조건 충돌 발생.
* **해법**: `CREATE_NEW` 선택 시 `User.email`을 `null`로 처리하고 `SocialAccount.email`에 개별 보존하여 1인 N개 소셜계정 독립 연동 구조 구현.

### 2. 정부 공공 API 신청 시 'LBS 사업자 신고' 장벽
* **문제**: e하늘 장례정보 API 이용 시 위치기반서비스(LBS) 사업자 신고(방통위) 필요 및 세부 단가 데이터 결여.
* **해법**: 행정 절차 대신 **카카오 로컬 REST API (`query=장례식장`) + 보건복지부 CSV 파싱 시딩** 기법으로 LBS 신고 없이 전국 1,500개 이상 시설 실데이터 100% 확보.

### 3. PostgreSQL 포트 충돌 (기본 5432 포트)
* **문제**: 개발자 로컬 PC의 타 프로젝트 PostgreSQL(5432 포트)과 포트 충돌 발생.
* **해법**: Docker 컨테이너 호스트 포트를 `5433`으로 우회 매핑(`5433:5432`)하여 타 서비스와의 충돌을 완전 예방.

### 4. 로컬 IP 테스트 시 Geolocation API 보안 컨텍스트(Secure Context) 제한 🌟 (신규)
* **문제**: 
  * 브라우저의 Geolocation API(`navigator.geolocation`)는 보안 정책상 **보안 컨텍스트(`https://` 또는 `localhost`)**에서만 동작함.
  * 개발 중 사설 LAN IP(`http://192.168.x.x:5173`)로 접속하면 `http://`로 판정되어 위치 자동 감지가 항상 실패하고 하드코딩 폴백(서울 서초 좌표)으로 무조건 떨어지는 문제 발생.
* **대안 검토 결과**:
  * `Certbot`: Let's Encrypt는 공인 도메인 전용으로 사설 IP/localhost 발급 불가.
  * `OpenSSL 자체 서명`: 브라우저 레드 스크린 경고 발생 및 최신 크롬 SAN(Subject Alternative Name) 설정 작성 까다로움.
  * `Cloudflare Tunnel`: 테스트 범위를 넘어 진짜 인터넷에 개발 서버가 노출되는 위험 존재.
* **해법 (`mkcert` 도입 및 구축)**:
  * 로컬 전용 CA(인증기관) 래퍼 도구인 **`mkcert`**를 채택하여 신뢰할 수 있는 개발용 SSL/TLS 인증서 자동 발급 및 적용.

## 🔒 [부록] `mkcert` 기반 로컬 HTTPS 구축 및 가이드

### 1) `mkcert` 설치 및 로컬 CA 등록 (윈도우)
```powershell
# Chocolatey 사용 시
choco install mkcert

# Scoop 사용 시
scoop install mkcert

# 윈도우 신뢰 인증서 저장소에 로컬 CA 등록
mkcert -install
```

### 2) 인증서 발급 (`eobom/` 디렉토리)
```powershell
# localhost, 127.0.0.1 및 내부 사설 IP용 인증서 통합 발급
mkcert localhost 127.0.0.1 192.168.0.111
# 생성 파일: localhost+2.pem (인증서), localhost+2-key.pem (개인키)
```

### 3) 프론트엔드/백엔드 SSL 적용
* **Vite ([`vite.config.ts`](../../eobom/frontend/vite.config.ts))**: `https: { key: fs.readFileSync(...), cert: fs.readFileSync(...) }` 세팅.
* **Express ([`server.ts`](../../eobom/backend/src/server.ts))**: `https.createServer({ key, cert }, app)`을 통해 5000번 포트를 HTTPS로 구동.

### 4) 복원 (Uninstall)
테스트 완료 후 언제든 원복 가능:
```powershell
mkcert -uninstall
```
