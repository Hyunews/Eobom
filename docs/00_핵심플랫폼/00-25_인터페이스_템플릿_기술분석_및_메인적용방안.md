### 2.1 Split-Flap Display & Web Audio 신시사이저 (`components/split-flap-text.tsx`)
공항이나 기차역의 **솔라리 보드(Solari Split-Flap Board)**를 디지털로 완벽하게 재현한 3D 플립 텍스트 컴포넌트입니다.

```tsx
// 1. Web Audio API를 이용한 외부 사운드 파일 없는 실시간 기계식 타격음 합성
const oscillator = ctx.createOscillator();
const gainNode = ctx.createGain();
const filter = ctx.createBiquadFilter();

oscillator.type = "square";
oscillator.frequency.setValueAtTime(800 + Math.random() * 400, ctx.currentTime);
oscillator.frequency.exponentialRampToValueAtTime(200, ctx.currentTime + 0.015);

filter.type = "bandpass";
filter.frequency.setValueAtTime(1200, ctx.currentTime);
filter.Q.setValueAtTime(0.8, ctx.currentTime);

gainNode.gain.setValueAtTime(0.05, ctx.currentTime);
gainNode.gain.exponentialRampToValueAtTime(0.001, ctx.currentTime + 0.02);

// 2. Framer Motion 3D 상/하단 분할 플랩 애니메이션
<motion.div
  key={`${animationKey}-${isSettled}`}
  initial={{ rotateX: -90 }}
  animate={{ rotateX: 0 }}
  transition={{ delay: tileDelay, duration: 0.25, ease: [0.22, 0.61, 0.36, 1] }}
  style={{ transformStyle: "preserve-3d", backfaceVisibility: "hidden" }}
>
  {/* 플립 분할 문자 렌더링 */}
</motion.div>
```

- **기술 포인트**: 
  - `AudioContext`의 `square` 파형과 `bandpass` 필터로 15ms 미세 타격음 실시간 생성 (네트워크 트래픽 0B).
  - 문자가 순차적으로 회전(Flip)하며 최종 텍스트로 안착(Settling)하는 물리 엔진 효과.
  - 마우스 호버 시 재트리거 및 사운드 Mute/Unmute 글로벌 컨텍스트 연동.

### 2.2 Scramble Text Decoder (`components/scramble-text.tsx`)
사이버펑크 및 하이테크 에디토리얼에서 쓰이는 **글리치 텍스트 디코더** 효과입니다.

```tsx
const GLYPHS = "!@#$%^&*()_+-=<>?/\\[]{}Xx";

function runScrambleAnimation(text, duration, setDisplayText, onComplete) {
  const lockedIndices = new Set();
  const finalChars = text.split("");
  const totalChars = finalChars.length;
  const scrambleObj = { progress: 0 };

  return gsap.to(scrambleObj, {
    progress: 1,
    duration,
    ease: "power2.out",
    onUpdate: () => {
      const numLocked = Math.floor(scrambleObj.progress * totalChars);
      for (let i = 0; i < numLocked; i++) lockedIndices.add(i);

      const newDisplay = finalChars
        .map((char, i) => (lockedIndices.has(i) ? char : GLYPHS[Math.floor(Math.random() * GLYPHS.length)]))
        .join("");

      setDisplayText(newDisplay);
    },
    onComplete: () => {
      setDisplayText(text);
      onComplete?.();
    }
  });
}
```

- **기술 포인트**:
  - GSAP `power2.out` 트윈 진행률(`progress: 0 ➔ 1`)에 따라 좌측부터 글자가 하나씩 고정(Locking)되는 정교한 계산 로직.
  - 버튼 호버(`ScrambleTextOnHover`) 및 페이지 마운트(`ScrambleText`) 시 인터랙션 부여.

### 3.1 걷어낼 과도한 요소 (De-cluttering & Tone Down)
1. **기계식 타격음 사운드(Web Audio API)**: 
   - ❌ *기각 사유*: 상례 및 웰다잉 플랫폼의 경건하고 차분한 분위기에 기계식 타격음은 불필요한 소음과 거부감을 줄 수 있음. ➔ **완전 배제(음소거).**
2. **사이버펑크 글리치 텍스트 (Scramble with `!@#$%`)**:
   - ❌ *기각 사유*: 6070 시니어 사용자에게 버그나 오류로 오인될 위험이 있음. ➔ 대신 **단아하고 정갈한 페이드인 & 부드러운 스트로크 텍스트**로 대체.
3. **차가운 잉크 블랙 배경**:
   - ❌ *기각 사유*: 브랜드 고유 자산인 **소프트 웜 크림(`#FBF9F5`)**을 전역 배경으로 100% 유지.
