## 🧭 4. 법 밖에서 남길 가치가 있는 기록 — 기획 판단

### 4.1 에러 기록 (C)
지금은 운영에서 500이 나도 **사용자가 말해주지 않으면 모릅니다.** 10-01 운영자 로그인 500(마이그레이션 누락)이 로컬이라
금방 잡혔을 뿐, 운영이었다면 원인을 추적할 기록이 7일 뒤 사라집니다.
- 남길 것: 시각 · **요청 번호**(§5.2 ③) · 경로 · 상태 코드 · 에러 종류 · 메시지(🔴 마스킹) · 스택 앞부분 · 주체 종류·내부 id
- 🔴 **요청 본문·응답 본문은 남기지 않는다**(엔딩노트 저장 중 에러가 나면 본문이 통째로 로그에 남는다)

### 4.2 보안 이벤트 (G)
- 로그인 실패(회원은 소셜이라 해당 적음 · **사업자·전문가·운영자** 비밀번호 로그인) · 운영자 **잠금 발생** · refresh 토큰 재사용 탐지 · 권한 거부(401/403)
- 따로 표를 만들지 않고 **A(접속기록)의 상태 코드 + B(운영자 감사)의 로그인 행동**으로 대부분 잡힌다. 잠금 발생만 B에 행동으로 추가

### 4.3 사후개봉 열람 기록 (E) — 🔴 이어봄에만 있는 기록
엔딩노트는 **고인이 남긴 유언·바람**이고, 개봉 뒤 **지정 가족 여러 명이 열람**합니다(`00-41`). 상속·유언 분쟁에서
*"누가 언제 처음 봤는가"* 는 유족끼리 다투는 지점이 될 수 있고, 이어봄이 답할 수 있어야 신뢰가 섭니다.
- 남길 것: 열람자(회원 id) · 대상 엔딩노트 id · 열람 시각 · 열람한 **섹션 종류**(유언·메시지 등 — 🔴 **내용 아님**) · IP
- 열람자 본인과 다른 지정 가족이 볼 수 있게 할지는 **화면 결정**(§9 #5) — 기록은 먼저 쌓는다

### 4.4 동의 이력 (D)
- 지금 구조는 *"현재 동의했는가"* 만 답합니다. **"언제 철회했다가 다시 동의했는가"**, **"어느 약관 버전에 동의했는가"** 는 답하지 못합니다.
- 약관이 개정되면(`00-21` 개정 조항) **누가 옛 버전에만 동의했는지** 가려야 재동의를 받을 수 있습니다 — 오늘(10-01) 운영 9명 중 7명이 동의 기록 없음으로 드러난 일과 같은 구멍입니다.
- 남길 것: 회원 id · 동의 종류(약관·개인정보·마케팅) · 동의/철회 · **약관 버전** · 경로(가입·재동의 창·마이페이지) · 시각
- `User`의 현재 값 칸은 **그대로 둡니다**(화면이 쓰는 빠른 값). 이력 표는 **추가만** 합니다.

### 4.5 파기 기록 일원화 (F)
- 계정 파기(익명화)·추모관 파기도 **유족 메시지 파기와 같은 수준**으로 남깁니다: 실행자 · 대상 종류 · 대상 id 목록 · 건수 · 시각.
- 🔴 **파기한 내용은 남기지 않는다**(파기 기록이 파기를 무효로 만들면 안 된다).
- `FarewellPurgeAuditLog`를 일반화할지, `AdminAuditLog`의 `PURGE` 행동으로 합칠지는 구현이 정합니다 — `00-37` §7 #2(신설 후 파기로그 유지)와 충돌하지 않게.

### 4.6 외부 연동 · 응답 시간 (H) — 공개 뒤
- 카카오(지도·로컬·로그인) · 네이버·구글 로그인 · CLOVA OCR·STT · R2 — **실패 건수·평균 응답 시간 집계**만.
- 응답 시간은 **인프라 이전 판단 근거**가 됩니다(`00-11` §8 — oregon↔서울 DB 1.5초 실측). A의 `응답시간 ms` 칸으로 대부분 대신합니다.

### 4.7 사업 지표 — 🟡 **새 로그를 만들지 않습니다**
가입 수 · 문의(`Lead`) · 전화 클릭(`Lead` `CALL`, `00-36` §4.4-1) · 상담 신청(`ConsultRequest`) · 추모관·부고장 개설은
**이미 DB 행으로 존재**합니다. 필요한 건 로그가 아니라 **집계 화면**이고, 그건 보류된 `00-37` A-3 홈 대시보드 몫입니다.

### 4.8 프론트 에러 — 공개 뒤
화면이 하얗게 멈추는 오류(React 렌더 실패)는 서버가 모릅니다. 서버에 **에러 접수 API**를 두고 C와 같은 표에 넣는 방식(외부 도구 없음).
요청 폭주를 막는 제한과 함께 — **공개 뒤 2순위**.

### 4.9 🔴 남기지 않는 것 — 금지 목록

| 금지 | 이유 |
| :--- | :--- |

## 🛠️ 5. 설계

### 5.1 기록 네 묶음

| 묶음 | 담는 것 | 한 행 | 보관 |
| :--- | :--- | :--- | :---: |
| **① 접속기록** (A·G·H) | API 요청 | 시각 · 요청 번호 · 주체 종류(익명/회원/사업자/전문가/운영자) · 주체 id · IP · 메서드 · **경로(쿼리 제거)** · 상태 코드 · 응답 시간 | **1년** |
| **② 운영자 감사기록** (B·G) | 운영자의 **모든** 행동 | 기존 `AdminAuditLog` + **IP** · **결과(성공/실패)** · 행동 추가(`LOGIN`·`LOGIN_FAIL`·`LOCKED`·`LIST`·`UPDATE` 등) | **2년** |
| **③ 에러 기록** (C) | 서버 에러(5xx·처리 못 한 예외) | 시각 · 요청 번호 · 경로 · 상태 · 에러 종류 · 메시지(마스킹) · 스택 앞부분 | **90일** |
| **④ 업무 증빙** (D·E·F) | 동의 이력 · 사후개봉 열람 · 파기 | 각 §4.3~4.5 | 동의 = **회원 탈퇴 후 1년**(분쟁 대비) · 열람 = **엔딩노트 파기 시까지** · 파기 = **2년** |

> 🟡 **①의 범위 — 축소안 권고**(§9 #1): **로그인한 요청 전부 + 모든 쓰기(POST·PATCH·DELETE) + 모든 실패(4xx·5xx)**.
> 빠지는 것은 *비로그인 공개 조회의 성공 응답*(시설 검색·부고장 열람 등)뿐입니다. 처리방침의 *"1년"* 은 **보관 상한**이라
> 덜 남기는 것은 약속 위반이 아니고, 용량(§6)이 대부분 여기서 나옵니다. 🔴 단, 통신비밀보호법이 해당되면(`미확인`) 전부로 넓힙니다.

### 5.2 공통 규칙

1. **남길 칸을 골라 담는다(허용 목록).** "본문에서 비밀번호만 빼고" 식의 금지 목록 방식은 새 칸이 생길 때마다 샌다.
2. 🔴 **경로에서 쿼리 문자열을 지운다.** `/api/geo/reverse?lat=..&lng=..` → `/api/geo/reverse`. 경로 안의 id(`/memorials/:id`)는 남긴다.
3. **요청 번호** — 모든 요청에 번호를 붙여 응답 헤더로 돌려주고, 에러 화면에 *"오류 번호: ○○○"* 로 보여준다. 사용자가 문의하면 그 번호로 ①·③을 찾는다. 문구는 사실만(`00-39` 문구 규칙).
4. **IP는 프록시 뒤 실제 주소로.** Render 앞단을 거치므로 Express `trust proxy` 설정 후 기록(안 하면 전부 Render 내부 IP가 찍힌다).
5. **기록 실패가 서비스를 멈추지 않는다** — ①·③은 실패해도 원래 요청은 그대로. 🔴 **예외: 운영자의 개인정보 열람**(회원 상세·상담 신청 목록 등)은 **②를 못 쓰면 응답하지 않는다**(기록 없는 열람을 만들지 않는다).
6. **위·변조 방지(3.1 ③)** — 기록 표에는 앱이 **추가만** 한다(수정·삭제 API 없음). 지우는 것은 **보관기간이 지난 행을 파기 배치가** 할 때뿐이고, 그 파기도 ④에 남긴다. DB 계정 권한 분리는 인프라 이전 때(`00-11` §8).
7. **시각은 UTC 저장**, 화면·내보내기 표시만 한국 시간(`51bab33`).
   🔵 10-01 경위 — 로그 3개 표를 KST 저장으로 바꿨다가(`b12d499`) 한 표 안에 UTC·KST가 섞여 **되돌림**(Prisma가 DB 시각을 항상 UTC로 다루기 때문).
   🟡 **DB를 직접 볼 때(Supabase 표 화면·psql·Prisma Studio) 한국 시간** — 10-01 개발자 결정: `createdAt`이 있는 **모든 표에
   보기 전용 칸 `createdAtKst`**(DB 트리거가 `createdAt + 9시간`으로 채움). 🔴 **앱 코드는 이 칸을 읽지도 쓰지도 않는다.**
   새 표에도 같은 트리거를 붙인다(`systems.md`). ✅ 10-01 운영 반영(`3e2f435`·`9d29b07`·`85df32e` — 응답에서도 제외).
   🆕 10-01 개발자 요청 — **`updatedAt`에도 `updatedAtKst`** 같은 방식으로 추가(진행 중). 그 밖의 시각 칸은 필요할 때 하나씩.
8. **보관기간이 지나면 파기** — 기존 파기 배치(`npm run purge` · 어드민 파기 탭)에 대상으로 추가.
