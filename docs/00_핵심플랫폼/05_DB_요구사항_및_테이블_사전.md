# 🗄️ 05. DB 요구사항 및 테이블 사전 (Prisma Schema)

> **문서 목적**: 이어봄 (Eobom) PostgreSQL 데이터베이스(`eobom_db`)의 핵심 테이블 스키마 컬럼 및 관계(Relationship) 사전을 정의합니다.

---

## 📋 핵심 테이블 스키마 사전

1. **`User` (유저 마스터)**: `id`, `email` (대표 이메일, UNIQUE/NULLABLE), `name`, `createdAt`
2. **`SocialAccount` (소셜 계정 1:N)**: `id`, `userId`, `provider` ("kakao"|"naver"|"google"), `providerId`, `email`, `unlinkedAt`
3. **`Facility` (시설 마스터)**: `id`, `name`, `type`, `location`, `lat`, `lng`, `price`, `priceValue`, `rating`, `isPartner`, `vrImages`
4. **`FacilityReview` (시설 리뷰)**: `id`, `facilityId`, `userId`, `rating`, `content`, `createdAt`
5. **`FacilityBooking` (답사 예약)**: `id`, `facilityId`, `userId`, `userName`, `userPhone`, `bookingDate`, `status`
6. **`Will` (엔딩노트 금고)**: `id`, `userId`, `encryptedContent` (AES-256), `deliveryTiming`, `createdAt`
