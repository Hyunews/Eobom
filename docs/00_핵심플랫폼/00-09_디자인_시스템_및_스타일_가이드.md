### 2.3 접근성 토큰 — **협상 대상이 아님** (2026-08-11 문서화)

`00-02`의 주 페르소나가 **6070 시니어**입니다. 아래 3개 값은 그 페르소나를 위한 최소 보장선이며, 화면이 빽빽해 보인다는 이유로 줄이지 않습니다. `index.css`의 `:root`에 토큰으로 선언돼 있습니다.

| 토큰 | 값 | 의미 |
| :--- | :--- | :--- |
| `--base-font-size` | `18px` | 본문 기준 크기. 일반 웹 기본값(16px)보다 크게 잡은 의도적 선택 |
| `--min-touch-target` | `56px` | 주요 버튼(`.btn`)의 높이. 손떨림·정확도 저하를 감안한 터치 타겟 |
| `line-height` | `1.7` | `body` 기본 행간 |

> **이 값들이 문서에 없어서 생긴 실제 문제**: 2026-08-11 밀도 조정 작업에서 여백을 줄이는 김에 이 토큰들도 함께 줄일 수 있었으나, 근거가 문서에 없어 매번 "줄여도 되나"를 재판단해야 했습니다. **그래서 여기에 정본을 세웁니다.** 밀도 조정은 여백(`padding`/`margin`/`gap`)만 건드리고 위 3개는 유지합니다.

### 2.4 여백 스케일 (2026-08-11 전면 조정)

초기 구현이 여백을 과하게 잡아 한 화면에 담기는 정보가 지나치게 적었습니다. **접근성 토큰(§2.3)은 그대로 두고 여백만 약 25~30% 축소**했습니다.

| 대상 | 이전 | 현재 |
| :--- | :--- | :--- |
| `.container` padding | `2.5rem 24px` | `1.75rem 24px` |
| `.card` padding | `2rem` | `1.5rem` |
| `.grid` gap | `2rem` | `1.5rem` |
| `.form-group` margin-bottom | `1.5rem` | `1.1rem` |
| `.hero-section` margin-bottom | `3.5rem` | `2.25rem` |

* 인라인 스타일에도 같은 비율을 적용하되 **대략 `1.25rem`(20px) 이상인 값만** 대상으로 합니다. `0.5rem` 이하의 작은 간격까지 줄이면 요소가 서로 붙어버립니다.
* 페이지별 인라인 여백이 많은 것은 구조적 부채입니다 — 신규 화면은 되도록 공통 클래스(`.container`/`.card`/`.grid`)를 쓰십시오.

### 2.5 운영자 화면 예외 — 밀도 우선 (2026-08-11)

`AdminPage.tsx`(운영자 대시보드)는 **§2.3 접근성 토큰의 적용 대상이 아닙니다.**

| 구분 | 소비자 화면 | 운영자 화면 |
| :--- | :--- | :--- |
| 사용자 | 6070 시니어 유족 | 내부 운영 담당자 |
| 사용 맥락 | 드물게, 경황 없는 상태에서 | 매일, 업무로 반복 |
| 우선순위 | 큰 글씨·큰 버튼 | 한 화면에 많이 보이기 |

운영자 화면에서 `.btn`(56px)을 그대로 쓰면 0.8rem 설명 텍스트 옆에 1.1rem 버튼이 붙어 **위계가 뒤집힙니다**(실제로 2026-08-11에 지적된 문제). 그래서 `AdminPage.tsx` 안에 로컬 상수 `SMALL_BTN`(34px) / `TAB_BTN`(38px) / `SMALL_INPUT`(38px)을 두고 카드 내부 요소에 적용합니다.

* **전역 `.btn`을 고치지 않습니다** — 소비자 화면 CTA가 같이 작아지면 §2.3 위반입니다.
* 목록 카드의 제목은 `font-size`를 **명시**하십시오. 생략하면 `<strong>`이 `body`의 18px을 상속받아 본문(0.85rem)과 위계가 어긋납니다.
* 이 예외는 **운영자 전용 화면에만** 적용합니다. 사업자·전문가가 쓰는 `BizDashboard`는 외부 사용자 화면이므로 소비자 기준을 따릅니다.

## 🧩 4. Component Micro-Interactions & Effects

1. **Card Hover Animation**:
   `transform: translateY(-4px)`, `box-shadow: 0 12px 24px rgba(0,0,0,0.08)`, `transition: all 0.25s ease`.
2. **Glassmorphism Blur Overlay**:
   `background: rgba(26, 43, 76, 0.75)`, `backdrop-filter: blur(8px)` (미인증/보호 구역).
3. **Pulsing Keyframes** (`.animate-pulse`, `animation: pulse 1.6s ease-in-out infinite`):
   `@keyframes pulse { 0%, 100% { opacity: 1; transform: scale(1); } 50% { opacity: 0.6; transform: scale(1.15); } }`
   * 🔵 **2026-08-19 정정**: 종전에는 이름이 *"Emergency"* 이고 값이 `50% { opacity: 0.5; }` 였으나, **실제 코드는 `opacity: 0.6` + `transform: scale(1.15)`** 이고 **유일한 사용처는 긴급 버튼이 아니라 `KakaoMapModal`의 지도 핀 마커**입니다(전수 검색 1건). 긴급 FAB이 제거되면서 이름이 실체와 어긋났습니다(→ §3.1).
   * ⚠️ `index.css:127`의 주석은 아직 *"Emergency Hotline Pulsing Badge"* 입니다 — **코드 주석 정정은 `[Claude:Sonnet]` 몫**이라 이 문서에서는 사실만 기록합니다.
