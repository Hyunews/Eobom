# 🎨 11. 디자인 시스템 및 스타일 가이드 (Design System & Style Guide)

> **문서 목적**: 이어봄 (Eobom) 브랜딩 자산(`Design_Logo.png`) 기반의 **공식 디자인 시스템, 컬러 토큰, 타이포그래피, UI 레이아웃 및 반응형 스타일 가이드**를 정의합니다.

---

## 🌿 1. Brand Visual Aesthetics

* **Brand Name**: 이어봄 (Eobom) / DEWD (Digital Ending & Well-Dying Total Care)
* **Symbolmark Concept**:
  * **무한대 연상 곡선**: 영원함, 연속성, 끝없는 동행
  * **봄의 잎사귀**: 새로운 시작, 온기, 희망
  * **두 손의 악수**: 연결, 신뢰, 함께하는 케어
* **Visual Identity Philosophy**:
  * 존엄함(Dignity), 평온함(Serenity), 따뜻함(Warmth), 현대적 품격(Modern Elegance).
  * 소프트 웜 크림(`#FBF9F5`) 바탕의 눈이 편안한 오가닉 비주얼.
  * 12px ~ 24px의 부드러운 둥근 모서리(Rounded Corners) 카드 시스템.

## 🖌️ 2. Design Tokens & Color Palette

### 2.1 3대 핵심 브랜드 컬러 & 액센트 토큰

| 구분 | 색상명 | Hex Code | 주요 적용 컴포넌트 |
| :--- | :--- | :--- | :--- |
| **Primary** | **Deep Navy (딥 네이비)** | `#1A2B4C` | 헤더, 주 헤드라인, 1차 액션 버튼, 다크 카드 표면, 푸터 배경 |
| **Secondary** | **Warm Green (웜 그린)** | `#5B7065` | 서브 포인트, 완결 뱃지, 수목장/생태 뱃지, 강조 아이콘 |
| **Accent** | **Warm Gold (웜 골드)** | `#D4A359` | 프리미엄 뱃지, 하이라이트 아이콘, 서체 강조, 골드 테두리 |
| **Background** | **Soft Cream White** | `#FBF9F5` | 메인 앱 전역 백그라운드 (눈이 편안한 소프트 웜 톤) |
| **Surface** | **Pure White** | `#FFFFFF` | 기본 대시보드 카드, 입력 폼 박스, 모달 배경 |
| **Alert** | **Crimson Red** | `#EF4444` / `#DC2626` | 24시간 긴급 콜 FAB 버튼, 긴급 알림 뱃지 (`.animate-pulse`) |

### 2.2 Typography System

* **Primary Font (UI & Body)**: `'Pretendard'`, `'Noto Sans KR'`, `sans-serif`
* **Title & Serif Font**: `'KoPubWorld 명조'`, `'KoPub World Batang'`, `serif`
* **Text Colors**:
  * **Primary Text**: `#1A2B4C` (가독성 높은 슬레이트 딥 네이비)
  * **Secondary / Muted**: `#6C7A89` (보조 설명, 날짜, 주소)
  * **Hint / Placeholder**: `#94A3B8` (입력창 힌트)
  * **On Navy Light Text**: `#FBF9F5` / `#FFFFFF` (다크 표면 전용)

## 📐 3. Layout & Responsive Breakpoints

### 3.1 Global Container & Grid Rules

* **Max Desktop Container**: `max-width: 1440px`, `margin: 0 auto`, `padding: 0 24px`
* **Desktop Layout Structure**:
  * **Top Header (100% Width)**: 브랜드 로고 + 로그인/회원가입 프로필 칩
  * **Left Collapsible Sidebar**: 7대 핵심 서비스 반응형 사이드바 (마우스 호버 시 텍스트 확장)
  * **Bottom-Right Floating FAB**: `🚨 24시간 긴급 콜` (`.animate-pulse` 깜빡임)
* **Responsive Breakpoints**:
  * **Desktop (>= 1024px)**: 3~4컬럼 반응형 그리드 (`repeat(auto-fit, minmax(300px, 1fr))`)
  * **Tablet (768px ~ 1023px)**: 2컬럼 그리드
  * **Mobile (< 768px)**: 1컬럼 스택 카드 + 반응형 햄버거/하단 탭바

---

## 🧩 4. Component Micro-Interactions & Effects

1. **Card Hover Animation**:
   `transform: translateY(-4px)`, `box-shadow: 0 12px 24px rgba(0,0,0,0.08)`, `transition: all 0.25s ease`.
2. **Glassmorphism Blur Overlay**:
   `background: rgba(26, 43, 76, 0.75)`, `backdrop-filter: blur(8px)` (미인증/보호 구역).
3. **Emergency Pulsing Keyframes**:
   `@keyframes pulse { 0%, 100% { opacity: 1; } 50% { opacity: 0.5; } }`
