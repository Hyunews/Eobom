## 📐 1. 시스템 토폴로지 (System Topology)

```
[ Frontend: React 18 + Vite + TypeScript, react-router-dom ]   운영: Vercel
              │
              ├── REST API / JSON — 브라우저 fetch 래퍼(lib/api.ts apiFetch), JWT는 Authorization 헤더
              ▼
[ Backend: Node.js + Express API 서버 ]   로컬: Port 5000 · 운영: Render 웹서비스
              │
              ├── Prisma ORM
              ├── Passport.js 전략(Kakao · Naver · Google) — config/passport.ts
              ├── AES-256-GCM 필드 암호화 — utils/crypto.ts
              │
              ├──▶ [ Database: PostgreSQL ]   로컬: Docker eobom-postgres (Port 5433) · 운영: Supabase(서울)
              │        모델 목록은 00-05 자동 생성 표가 정본
              │
              └──▶ [ 파일 저장소: Cloudflare R2 ]   버킷 구성 = 00-11 §5.4-6
                       유족 메시지 음성 → 아카이브 사본은 Worker(workers/r2-archive-relay)가 복제
```

- 외부 연동(OAuth·지도·공공데이터·CLOVA OCR/STT)의 설정 정본은 `.harness/systems.md`입니다.

## 🔒 2. 보안 & 암호화 메커니즘

> **암호화 대상·키 3종의 정본은 `00-33` §2.1입니다.** 이 절은 요약만 둡니다.
> 🔴 결정 대기: 이 절을 `00-33`으로 통합(여기는 링크만)할지 — 사람 결정.

1. **필드 암호화**: 엔딩노트 항목·유족 메시지 본문(`EndingNoteEntry`·`FarewellMessage`의 `bodyEnc`)과 정산 계좌·부고 계좌·가족 연락처를 `crypto` 모듈 **AES-256-GCM**으로 암호화해 DB에 보관합니다(`utils/crypto.ts` `encryptField`·`encryptNoteField`).
2. **인증 토큰**: JWT를 발급해 `Authorization` 헤더로 보냅니다. 회원 12시간 · 사업자/전문가/운영자 2시간 + 리프레시(정본 `00-04` §0 · `00-08`).
3. **계정 통합 보안**: 동일 이메일 멀티 소셜 연동 시 10분 만료 서명된 OAuth state로 소유권을 검증합니다(`00-08`).

## 📎 부록: 경위 — 처음 그린 토폴로지

처음 판은 아래처럼 그렸습니다. 2026-10-12 4단계에서 지금 코드 기준으로 고쳤습니다.
- **Axios**는 쓰지 않습니다(프론트 의존성에 없음 — `apiFetch` fetch 래퍼).
- **`wills` 테이블은 없습니다** — 엔딩노트는 `EndingNote`·`EndingNoteEntry` 등(`00-05`).
- 배포(Vercel + Render + Supabase)와 R2 저장소가 그림에 없었습니다.
- 🔵 10-01 판정 메모의 *"Passport.js 없음"* 은 틀렸습니다 — `backend/src/config/passport.ts`가 passport 전략 3종을 씁니다(10-12 확인).
- §2 1번의 원문 *"유언 메시지 및 자산 기록은 … 256-bit AES 암호화"* 는 실제 대상(`00-33` §2.1)과 달라 고쳤습니다.

```
[ Frontend: React 18 + Vite 5 + TypeScript ] (Vercel Host)
              │
              ├── REST API / JSON (Axios, Credentials Included)
              ▼
[ Backend: Node.js Express API Server ] (Port 5000)
              │

```
