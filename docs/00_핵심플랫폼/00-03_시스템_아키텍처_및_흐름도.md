## 📐 1. 시스템 토폴로지 (System Topology)

```
[ Frontend: React 18 + Vite 5 + TypeScript ] (Vercel Host)
              │
              ├── REST API / JSON (Axios, Credentials Included)
              ▼
[ Backend: Node.js Express API Server ] (Port 5000)
              │
              ├── Prisma ORM (Object-Relational Mapping)
              ├── Passport.js OAuth (Kakao, Naver, Google)
              │
              ▼
[ Database: PostgreSQL (Port 5433 / eobom_db) ]
              │
              ├── users (1 : N) social_accounts
              ├── facilities (1 : N) facility_reviews
              └── wills (256-bit AES Vault Encrypted)
```

---

## 🔒 2. 보안 & 암호화 메커니즘 (AES-256 Vault)

1. **디지털 엔딩노트 암호화**: 유저가 작성한 유언 메시지 및 자산 기록은 `crypto` 모듈 기반 **256-bit AES 암호화** 후 DB에 보존.
2. **소셜 인증 토큰 연동**: JWT (JSON Web Token) 쿠키 및 헤더 기반 단기 인증 발급.
3. **계정 통합 보안**: 동일 이메일 멀티 소셜 연동 시 10분 만료 서명된 OAuth State 기반 소유권 검증.
