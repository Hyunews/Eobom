🧩 5대 핵심 도메인 모듈 및 기술 요소

1. 장례·묘지 매칭 서비스 (`/facilities`)
  • 1.1 장례식장/상조 비교: 위치(LBS), 예산, 종교, 규모 기반 맞춤형 추천 알고리즘 엔진 탑재.
  • 1.2 묘지/봉안당 검색: Three.js/Panolens.js 기반 360° VR 가상 투어 및 답사 예약 캘린더.
  • 1.3 24/7 실시간 긴급 지원: Socket.io 기반 긴급 장례지도사 1-Touch 디스패치 및 실시간 트래킹.
2. 상속·법률·세무 서비스 (`/counseling`)
  • 2.1 전문가 1:1 상담: WebRTC 기반 화상/음성 상담, 전문가 일정 예약 및 결제(PG) 시스템.
  • 2.2 상속/증여세 시뮬레이터: 최신 국세청 공제율 및 과세표준 알고리즘 기반 자동 산출 엔진.
  • 2.3 유언장 작성 및 공증: KISA 연계 전자서명 및 변호사 공증 매칭 워크플로우.
3. 디지털 유품 정리 서비스 (`/digital-estate`)
  • 3.1 디지털 자산 정리: 고인 계정(SNS/이메일) 위임 서류 OCR(Naver/Tesseract) 자동 검증.
  • 3.2 현물 유품 정리: 청소/수거 업체 견적 산출 및 제휴 ERP 시스템 Webhook 연동.
  • 3.3 디지털 메모리얼: AWS S3 기반 고인 온라인 추모관, 방명록 및 모바일 앨범 생성기.
4. 디지털 엔딩노트 (보안 금고) (`/ending-note`)
  • 4.1 사전 의향서: 연명의료 중단 의향, 장례 희망 방식, 위시리스트 암호화 저장.
  • 4.2 비밀번호/자산 보관함: KISA 개인정보 암호화 가이드 준수 (AES-256-GCM 보안 금고).
  • 4.3 지정 수신인 유언 메시지: 사후 조건 충족 시 Cron 스케줄러 기반 알림톡/메일 발송.
5. 상중 케어 & 행정 가이드 (`/care-guide`)
  • 5.1 사망 후 행정절차 타임라인: 사망일 기준 D-Day별 행정 체크리스트 (정부24 안심상속 서비스 연계).
  • 5.2 모바일 부고장 & 답례품: Canvas/Puppeteer 기반 동적 OG 이미지 생성 및 카카오톡 공유 API.
  • 5.3 유족 심리 상담 케어: 헬스케어 전문가 1:1 심리 케어 세션 예약 및 트래킹 시스템.

🛠️ 기술 스택 및 인프라 요구사항 명세

구분 선택 기술 스택 (Tech Stack) 주요 역할 및 도입 사유
Frontend React 18, TypeScript, Vite, Vanilla CSS 빠른 번들링 speed, 시니어 접근성(18px+, 56px+) 반응형 UI 구현
Backend Node.js, Express, TypeScript, Prisma ORM 타입 안정성 보장, 높은 개발 생산성 및 RESTful API 구현
Database PostgreSQL 15, Redis 관계형 데이터(시설, 사용자, 예약) 관리 및 실시간 세션/캐싱
Security AES-256-GCM, Bcrypt, JWT, SSL/TLS 민감 자산 정보 및 엔딩노트 개인 금고 최고 수준 암호화 보관
Media/File AWS S3 / NCP Object Storage 추모 앨범, 유품 사진 및 증빙 서류 보안 업로드 저장소
External APIs 카카오맵 API, WebRTC, 정부24, 알림톡, PG사 위치 검색, 비대면 화상 통화, 사망 행정 연계 및 결제 처리

🗺️ 개발 단계별 추진 로드맵

Phase 1: MVP 중심 개발 (1~2개월)
  • 전국 장례식장 / 묘지 DB 구축 및 지도 기반 위치 검색 기능
  • 사망 후 행정절차 타임라인 가이드 및 모바일 부고장 생성기
Phase 2: 서비스 고도화 (3~4개월)
  • 맞춤 추천 알고리즘 적용 (Distance, Budget, Religion 스코어링)
  • 전문가 1:1 비대면 화상상담 시스템 & 디지털 엔딩노트 암호화 금고
Phase 3: 서비스 확장 (5~6개월)
  • 디지털 유품 정리 (서류 OCR 검증 & 제휴 ERP 연동)
  • 사후 지정 수신인 유언 메시지 자동 발송 및 디지털 메모리얼
