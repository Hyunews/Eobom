### 5. 메인 페이지 히어로 섹션 반응형 리디자인

**문제**: 기존 히어로 섹션이 고정 px 값 기반(height: 400px, 이미지 컬럼 420px)으로 작성되어, 브라우저 너비를 줄이면 텍스트 잘림·레이아웃 깨짐 발생.

**변경 파일**:
- [`well-dying-web/frontend/src/pages/HomePage.tsx`](file:///c:/Users/kilak/Desktop/DEWD/well-dying-web/frontend/src/pages/HomePage.tsx) — 히어로 인라인 스타일 제거, CSS 클래스 기반 마크업으로 전환
- [`well-dying-web/frontend/src/index.css`](file:///c:/Users/kilak/Desktop/DEWD/well-dying-web/frontend/src/index.css) — `.hero-*` 클래스 신규 추가, 반응형 브레이크포인트 정비

**핵심 변경**:
1. **그리드 컬럼**: `420px 고정` → `1fr 38%` (순수 비율, px 최솟값 없음) — px 최솟값이 있으면 좁은 화면에서 텍스트 컬럼이 0에 수렴하는 버그 발생
2. **폰트 크기**: `clamp(최솟값, vw, 최댓값)` 도입 — 1920px 해상도에서 제목 54px(3rem), 좁은 화면에서 최솟값 고정으로 안전 확보
3. **브레이크포인트**: `≤900px`에서 단일 컬럼 스택 전환, 이미지 `aspect-ratio: 16/9` + `max-height: 260px`
4. **사이드바 overlap 버그 수정**: 기존 `@media (max-width: 768px) { .main-wrapper { margin-left: 0 } }` 제거 — 사이드바가 `position: fixed; width: 72px`로 항상 존재하므로 margin-left를 0으로 만들면 콘텐츠가 사이드바에 덮임

**발견된 gotcha (feedback 메모리 후보)**:
- `min-width: 0`을 grid child에 적용 시 텍스트 컬럼 과도 압착 가능 → hero-text에는 미적용
- `overflow: hidden`을 grid child에 적용 시 왼쪽 텍스트 클리핑 발생 → section 레벨에만 적용
