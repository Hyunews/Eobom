## 2. 지도 / 위치

| 시스템 | 상태 | 비고 |
|---|---|---|
| 카카오맵 JS SDK | ✅ 활성 (2026-08-07 확인) | 등록 도메인에 로컬 LAN IP 추가함 (기존엔 localhost만 등록돼 있었음) |
| 카카오 로컬 API (장소검색) | ✅ 사용 중 | 시설 데이터 수집에 사용 |

- 키: `VITE_KAKAO_MAP_KEY` (`eobom/frontend/.env`) — 프론트 번들에 노출되므로 도메인 제한 필수
- 활성화 경로: 카카오 디벨로퍼 > 이어봄 앱 > 제품 설정 > 카카오맵 > 활성화 ON
- ⚠️ **수집 한계**: 시/도 단위 검색 시 45건 API 캡 때문에 일부 지역(예: 광주 남구) 시설이 누락된다. 전수 수집하려면 시/군/구 단위로 재검색해야 함.

### 위치(Geolocation) 자동감지 — mkcert 로컬 HTTPS로 로컬 검증 가능해짐 ✅

브라우저 `navigator.geolocation`은 보안 컨텍스트(HTTPS/`localhost`)에서만 동작 — LAN IP를 http로
접속하면 차단되어 하드코딩 폴백(서울 서초)으로 떨어짐. 2026-08-07 mkcert 로컬 인증서 도입 후
`https://localhost:5173`·`https://192.168.0.111:5173`에서 정상 동작 사용자 확인 완료
(권한 프롬프트·실제 위치·폴백배지 미노출 3항목).
⚠️ **주소창에 `https://`를 반드시 명시**해야 함 — 프로토콜 생략 시 브라우저가 `http://`로 기본
시도하는데 서버가 HTTP를 거부함(정상 동작, 버그 아님). 북마크 권장.

### 백엔드 배포 — Render (2026-08-07 결정)

**사용자 결정: 우선 Render 무료 티어로 배포, Oracle Cloud 등 다른 대안은 추후 재검토.**

- 설정 파일: 레포 루트 `render.yaml` (Blueprint) — `eobom/backend`를 `rootDir`로 지정, Postgres 포함
- 배포 도메인 고정: `https://eobom-backend.onrender.com` (render.yaml의 `name` 필드로 예측 가능하게 만듦 → 카카오/네이버/구글 콜백 URL도 미리 등록 가능)
- ⚠️ **무료 Postgres 30일 후 만료**(14일 유예 후 삭제, 백업 없음) — 30일 내(~2026-09-07) 결정 필요, pending-approvals.md 등록됨.
- ⚠️ 무료 웹 서비스는 15분 미사용 시 슬립(콜드 스타트 지연).
- 배포 후 할 일: (1) 카카오/네이버/구글 콘솔에 새 콜백 URL 등록(render.yaml 값 그대로) (2) Vercel env에 `VITE_BACKEND_URL=https://eobom-backend.onrender.com` 추가 (3) 새 DB에 시설 데이터 시딩 1회(`npm run seed`) — 마이그레이션은 `npm start`에 자동 포함, 시딩은 반복 위험 있어 수동.
