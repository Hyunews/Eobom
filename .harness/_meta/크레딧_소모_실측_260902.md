   200턴 남기고 열면 2.6M 캐시읽기 토큰, Opus 기준 약 $4. **Read 한 번의 값이다.**

## 3. 이번에 넣은 장치 3개

1. **통독 차단 — `tools/read-guard.js`** (`PreToolUse:Read` 훅, `.claude/settings.json`)
   **40KB 초과 파일을 `limit` 없이 `Read`하면 거부**하고 `grep -n` → `sed -n 'a,bp'` 경로를 알려준다.
   `limit ≤ 400`줄이면 통과 — 막는 게 아니라 **덩이로 끊어 읽게** 만든다. 이미지·PDF는 예외.
   🔵 6개 경로를 실제로 발화시켜 확인(작은파일 통과 / 통독 차단 / `limit=50` 통과 /
   `limit=9999` 차단 / 다른 도구 무시 / 없는 파일 무시). **못 잡는 검사는 초록불만 켠다.**
   🔴 **규칙이 아니라 코드로 넣은 이유**: 읽기 절제는 매 턴 반복되는 판단이라 규칙으로는 안 지켜진다
   (`db-safety.md` §7과 같은 논리). 되돌리려면 `settings.json`의 `PreToolUse` 블록을 지운다.
2. **계량 상설화 — `tools/usage-report.js`**
   날짜별 비용·**호출당 컨텍스트(avgCtx)**·세션 상위를 낸다. avgCtx 100K에서 🟡, 150K에서 🔴.
   🔴 **없으면 또 느낌으로 간다** — 지금까지 상한을 두 번 올린 것이 전부 실측 없이 내린 결정이었다.
3. **읽기 예산 규칙 — `AGENTS.md` §10** (부팅에 실린다, 약 0.5KB)
   훅이 못 막는 경로(`cat`·`git diff` 전량·광역 grep)와 **모델 배분**을 규칙으로 덮는다.

### 4-1. 덤으로 나온 것 — #8은 원래부터 잘못 세고 있었다

불변식을 넣자 빨간불이 켜졌고, 파고 보니 **분할과 무관한 기존 버그**였다. 옛 코드는
`<!-- Gemini 판정` 접두어를 **줄 단위**로 세어 ⓐ 이미 판정이 난 `<!-- Gemini 판정: ✅통과 …`
4건을 '대기'로 세고 ⓑ 본문 서술의 *"판정 대기"* 라는 말까지 셌다. `context.md`가 게이트 대기를
**16건**으로 적고 doctor는 **23건**을 찍고 있었는데, **실제는 19건**이었다 — 두 숫자 다 틀렸다.

- 표기가 역사적으로 갈려 있다: `판정 대기 -->` · `판정 1줄: -->` · `판정 1줄:`(안 채운 양식)
  · `판정: ✅통과 (…)`(채워짐) · `- **판정**:` · `- **판정(재)**:`. 게다가 **2026-08-07 5개 필드
  양식 이전 15건은 판정 필드가 아예 없다.**
- 🔴 **그래서 둘이 아니라 셋으로 센다 — 판정 / 대기 / 무표기.** 무표기를 '대기'에 합치면
  고칠 수 없는 **영구 빨간불**이 되고(→ 빨간불 무시 습관), '판정'에 합치면 게이트를 안 거친
  항목이 통과로 둔갑한다. **셋의 합 ≠ 항목 수면 실패** 검산을 붙여 파서가 조용히 틀리지 않게 했다.
- 🔴 **패턴은 전부 줄 첫머리에 앵커했다.** 앵커 없이 짜면 *표기법을 설명하는 문장*이 판정으로
  세어진다 — 이번 세션에 **같은 부류를 세 번** 밟았다(아카이브 머리말 → 현행 머리말 →
  walkthrough 항목 본문). 문구를 피해 다니는 건 해법이 아니다. **구조로 막아야 한다.**
- 🔵 남은 한계: 판정 표기를 **새 형태로 쓰면 '무표기'로 떨어져 게이트 큐에서 조용히 사라진다.**
  그래서 무표기 건수를 화면에 같이 찍는다 — **15에서 늘어나면 새 표기를 쓴 것**이다.

## 5. 2차 조치 — 가드 임계 하향 + 로그 2종 아카이빙 (2026-09-02, 같은 날)

발단은 Gemini의 제안 3건이었다: **A** `walkthrough.md` 2차 아카이빙 · **B** `claude_tasks.md`
분할 · **C** 세션 규율. 실측에 대보니 **A·B는 컨텍스트 절감이 0에 가깝고, A는 역효과**였다.

- **왜 0인가**: 두 파일 모두 **이미 40KB 가드 위**라 통째로 실린 적이 없다. 실리는 건
  `grep`/`sed` 출력뿐이고 그 크기는 원본 크기와 무관하다.
- 🔴 **왜 역효과인가**: 141KB→43KB로 줄이면 **가드 밑으로 내려가 통독이 가능해진다.** 한 번
  열면 43KB(약 14K토큰)가 세션 남은 턴마다 재전송된다. **지금은 구조적으로 불가능한 사고를
  아카이빙이 가능하게 만든다.**
- **C는 새 제안이 아니었다** — `AGENTS.md` §10에 이미 있다(한 세션 한 과업·`/clear`, 단가 5배).
