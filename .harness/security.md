# security.md — 개인정보·시크릿·발행 게이트

> **언제 읽나**: 개인정보(유족·고인·상담자) 관련 코드/문서를 건드릴 때 / 시크릿·API 키를 다룰 때 / 외부에 무언가 공개·배포할 때
>
> 이어봄은 **사별·상속·유언**을 다룬다. 일반 웹서비스보다 민감도가 한 단계 높다는 전제로 작업한다.

---

## 1. 절대 금지 (예외 없음)

- **실제 개인정보를 저장소에 커밋하지 않는다.** 유족·고인·상담 신청자의 이름·연락처·주소·가족관계는 어떤 파일에도 원문으로 남기지 않는다. `docs/`·`reports/`·로그·테스트 픽스처 전부 해당.
- **시크릿을 코드·문서에 하드코딩하지 않는다.** OAuth 클라이언트 시크릿, JWT 서명키, DB 접속 문자열, 카카오 REST 키는 `.env`에만. `.env`는 `.gitignore`에 이미 포함되어 있다.
- **에러 메시지·로그에 개인정보를 흘리지 않는다.** 디버깅용 `console.log(user)` 같은 전체 객체 덤프 금지 — 필요하면 `user.id`만.

## 2. 예시·테스트 데이터는 반드시 가짜로

문서나 테스트에 사람 정보가 필요하면 명백한 더미를 쓴다.

| 쓰지 말 것 | 쓸 것 |
|---|---|
| 실제 지인 이름·전화번호 | `홍길동`, `010-0000-0000` |
| 실제 이메일 | `test@example.com` |
| 실제 주소 | `서울시 중구 세종대로 110` (공공청사) |

시설(장례식장·봉안시설) 정보는 공개된 공공데이터이므로 실제 값 사용 가능.

## 3. 시크릿 목록과 위치 (값은 절대 여기 안 적는다)

| 시크릿 | 위치 | 비고 |
|---|---|---|
| 카카오/네이버/구글 OAuth 클라이언트 시크릿 | `eobom/backend/.env` | 3사 소셜 로그인 |
| JWT 서명키 | `eobom/backend/.env` | |
| `DATABASE_URL` | `eobom/backend/.env` | 로컬 Docker Postgres |
| `VITE_KAKAO_MAP_KEY` | `eobom/frontend/.env` | **프론트 번들에 노출됨** — 도메인 제한 필수 |

> `VITE_` 접두사 변수는 빌드 결과물에 그대로 박힌다. 비밀이 아니라 "공개되지만 도메인으로 잠근 키"로 취급할 것.

## 4. 위치정보 (위치정보법)

`docs/01_장례_묘지_매칭/12_공공데이터_및_API_상업적_이용_법률_검토서.md`가 정본. 요약:

- **트랙 A — 실시간 GPS(`navigator.geolocation`)**: 위치정보사업자 **신고 대상**. 현재 사용자는 사업자 신고 전이므로 실서비스 전환 시 반드시 제거 또는 신고 완료 후 사용.
- **트랙 B — 시/도·시/군/구 수동 선택**: 신고 불필요. 실서비스 기본 경로로 삼는다.
- 현재 로컬 개발 단계에서는 A/B가 공존 중. **프로덕션 배포 전 A 제거 여부를 반드시 재확인**한다.

## 5. 발행 게이트 — 밖으로 나가는 것

아래는 실행 전 **사용자 승인 필수**. 되돌리기 어렵거나 외부에 노출되기 때문.

- `git push`, 공개 저장소 전환, 배포(Vercel 등)
- `reports/` 산출물을 사내·대외로 공유
- 외부 API에 실데이터 전송, 새 외부 서비스 연동

> 현재 저장소는 **private**(`github.com/Hyunews/Eobom`). public 전환 시 `docs/`·`reports/` 전체를 개인정보·사업 기밀 관점에서 재검토해야 한다.

## 6. 데이터 보호 (운영)

- **로컬 DB 백업**: 2026-08-05 마이그레이션 실수로 User/SocialAccount 데이터가 유실된 사고가 있었다. 스키마를 바꾸는 마이그레이션 전에는 `pg_dump`를 먼저 뜬다.
- **엔딩노트(계획 중)**: 사후 전달 콘텐츠는 저장 시 암호화(AES-256) 전제로 설계한다. 평문 저장 구현을 임시로라도 만들지 않는다 — 임시가 그대로 남는다.

## 7. 의심스러우면

판단이 안 서면 진행하지 말고 사용자에게 묻는다. 개인정보·법률 영역에서 에이전트의 자율 판단 범위는 **좁게** 잡는다.
