# 보고서 및 문서 산출물 단일 폴더 저장 지침

## 교정 내역
- **문제 현황**: 보고서(PDF, DOCX, HTML 등) 작성 시 `eobom/`와 `.harness/projects/eobom/` 두 곳 이상에 중복 파일이 사방으로 생성되어 폴더 구조가 지저분해지고 버전 파편화가 발생하는 문제 지적.
- **원인**: 편의를 위해 소스코드 폴더와 하네스 포인터 폴더 양쪽에 복사본을 동시 출력하던 습관.

## 확정 지침
1. **단일 저장소 고정**: 모든 보고서 산출물은 **단 하나의 지정 폴더**인 루트 `reports/` 내에만 보관하고 관리한다 (2026-08-07 하네스 재구성으로 `.harness/projects/eobom/reports/`에서 이동).
2. **중복 복사 금지**: 소스코드 워크스페이스(`eobom/`)나 기타 루트 폴더에 동일 보고서 파일을 임의로 중복 복사·생성하지 않는다.
3. **자동화 스크립트 고정**: 보고서 생성 파이썬 스크립트(`generate_pdf_report.py`)의 출력 경로를 `reports/` 전용 폴더로 고정한다.
4. **보고서 파일명 한글화 원칙**: `reports/` 폴더 내 저장되는 모든 보고서 및 기획 문서의 파일명은 영문 대신 **한글 파일명**으로 작성한다 (예: `DEWD_전체_폴더_구조_점검_보고서.html`).
