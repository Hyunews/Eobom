장례 견적 비교 데이터 한계 극복 3대 기획안

전국 1,100개 장례식장 데이터 제약 극복 및 UX · B2B 수익성 극대화 전략

📌 1. 문제 배경 및 핵심 과제

공공데이터 및 카카오 API는 장례식장의 이름, 주소, 위치 핀, 전화번호를 100% 제공하지만, 개별 장례식장의 5대 세부 항목(빈소, 안치실, 관/수의, 제단생화, 음식비) 단가는 공시 파편화로 인해 실시간 일괄 수집에 현실적 한계가 존재합니다. 세부 데이터 부재 상태에서도 첫날부터 100% 동작하는 UX 구축이 필요합니다.

💡 2. 3대 기획 대안 상세 비교

대안 A (강력 추천)

표준 장례비 시뮬레이터

보건복지부 표준 장례 통계 수가표를 기반으로 하객수/종교/규모 선택 시 예상 가이드 비용 산출.

  • 첫날 완성도: 100% 즉시 전국 구동
  • UX 만족도: 예산 가이드 제공
  • 개발 난이도: 매우 쉬움
대안 B

제휴 vs 비제휴 파트너 차별화

일반 시설은 기본 공시액, 제휴 파트너 시설은 어드민 등록 실시간 세부 견적표 및 할인가 노출.

  • B2B 수익 직결: 파트너 입점 명분 극대화
  • 세부 견적: 제휴 시설에 한해 100% 분해
  • 개발 난이도: 어드민 추가 개발
대안 C

1-Touch 맞춤 견적서 신청

[견적서 신청] 클릭 시 전문 장례지도사가 카카오 알림톡/전화로 최적 3곳 비교 견적 발송.

  • 데이터 정밀도: 100% 최신 실제 견적
  • 리드 유치: 유저 데이터 확보
  • 운영 부담: 상담원 리소스 필요
