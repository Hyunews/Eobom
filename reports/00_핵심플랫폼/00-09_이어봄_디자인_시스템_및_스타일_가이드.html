🎨 11. 디자인 시스템 및 스타일 가이드 (Design System & Style Guide)

문서 목적: 이어봄 (Eobom) 브랜딩 자산(Design_Logo.png) 기반의 공식 디자인 시스템, 컬러 토큰, 타이포그래피, UI 레이아웃 및 반응형 스타일 가이드를 정의합니다.

🌿 1. Brand Visual Aesthetics

  • Brand Name: 이어봄 (Eobom) / DEWD (Digital Ending & Well-Dying Total Care)
  • Symbolmark Concept:

* 무한대 연상 곡선: 영원함, 연속성, 끝없는 동행

* 봄의 잎사귀: 새로운 시작, 온기, 희망

* 두 손의 악수: 연결, 신뢰, 함께하는 케어

  • Visual Identity Philosophy:

* 존엄함(Dignity), 평온함(Serenity), 따뜻함(Warmth), 현대적 품격(Modern Elegance).

* 소프트 웜 크림(#FBF9F5) 바탕의 눈이 편안한 오가닉 비주얼.

* 12px ~ 24px의 부드러운 둥근 모서리(Rounded Corners) 카드 시스템.

이 값들이 문서에 없어서 생긴 실제 문제: 2026-08-11 밀도 조정 작업에서 여백을 줄이는 김에 이 토큰들도 함께 줄일 수 있었으나, 근거가 문서에 없어 매번 "줄여도 되나"를 재판단해야 했습니다. 그래서 여기에 정본을 세웁니다. 밀도 조정은 여백(padding/margin/gap)만 건드리고 위 3개는 유지합니다.

2.4 여백 스케일 (2026-08-11 전면 조정)

초기 구현이 여백을 과하게 잡아 한 화면에 담기는 정보가 지나치게 적었습니다. 접근성 토큰(§2.3)은 그대로 두고 여백만 약 25~30% 축소했습니다.

대상이전현재
.container padding2.5rem 24px1.75rem 24px
.card padding2rem1.5rem
.grid gap2rem1.5rem
.form-group margin-bottom1.5rem1.1rem
.hero-section margin-bottom3.5rem2.25rem
  • 인라인 스타일에도 같은 비율을 적용하되 대략 1.25rem(20px) 이상인 값만 대상으로 합니다. 0.5rem 이하의 작은 간격까지 줄이면 요소가 서로 붙어버립니다.
  • 페이지별 인라인 여백이 많은 것은 구조적 부채입니다 — 신규 화면은 되도록 공통 클래스(.container/.card/.grid)를 쓰십시오.

2.5 운영자 화면 예외 — 밀도 우선 (2026-08-11)

AdminPage.tsx(운영자 대시보드)는 §2.3 접근성 토큰의 적용 대상이 아닙니다.

구분소비자 화면운영자 화면
사용자6070 시니어 유족내부 운영 담당자
사용 맥락드물게, 경황 없는 상태에서매일, 업무로 반복
우선순위큰 글씨·큰 버튼한 화면에 많이 보이기

운영자 화면에서 .btn(56px)을 그대로 쓰면 0.8rem 설명 텍스트 옆에 1.1rem 버튼이 붙어 위계가 뒤집힙니다(실제로 2026-08-11에 지적된 문제). 그래서 AdminPage.tsx 안에 로컬 상수 SMALL_BTN(34px) / TAB_BTN(38px) / SMALL_INPUT(38px)을 두고 카드 내부 요소에 적용합니다.

  • 전역 .btn을 고치지 않습니다 — 소비자 화면 CTA가 같이 작아지면 §2.3 위반입니다.
  • 목록 카드의 제목은 font-size를 명시하십시오. 생략하면 <strong>이 body의 18px을 상속받아 본문(0.85rem)과 위계가 어긋납니다.
  • 이 예외는 운영자 전용 화면에만 적용합니다. 사업자·전문가가 쓰는 BizDashboard는 외부 사용자 화면이므로 소비자 기준을 따릅니다.

📐 3. Layout & Responsive Breakpoints

3.1 Global Container & Grid Rules

  • Max Desktop Container: max-width: 1440px, margin: 0 auto, padding: 1.75rem 24px (세로 여백 → §2.4)
  • Desktop Layout Structure:

* Top Header (100% Width, 고정 72px): 브랜드 로고 + 로그인/회원가입 프로필 칩

* Left Collapsible Sidebar: 6개 메뉴(메인 + 5대 도메인) 반응형 사이드바. position: fixed, 기본 72px → 마우스 호버 시 240px 확장. 메뉴 순서는 도메인 번호와 일치해야 합니다(→ 00_DOCS_INDEX.md 도메인 번호 체계).

* Bottom-Right Floating FAB: 🚨 24시간 긴급 콜 (.animate-pulse 깜빡임)

고정 크기(헤더 72px, 사이드바 72/240px)는 여백이 아니라 구조값입니다 — §2.4 밀도 조정 대상이 아닙니다. 사이드바 폭은 main-wrapper의 margin-left와 짝을 이루므로 한쪽만 바꾸면 레이아웃이 깨집니다.
  • Responsive Breakpoints:

* Desktop (>= 1024px): 3~4컬럼 반응형 그리드 (repeat(auto-fit, minmax(300px, 1fr)))

* Tablet (768px ~ 1023px): 2컬럼 그리드

* Mobile (< 768px): 1컬럼 스택 카드 + 반응형 햄버거/하단 탭바
