⚖️ 1. 이어봄 맞춤형 취사선택 (Selection Matrix)

interface 템플릿은 매우 현대적이지만, 자칫 과하면 6070 시니어 사용자 및 상례/웰다잉 플랫폼의 경건한 톤앤매너를 해칠 수 있습니다. 따라서 철저하게 "절제와 온기"를 기준으로 취사선택합니다.

템플릿 요소 판정 이유 및 대체 방안
기계식 클릭 사운드
(Web Audio Synth)		 ❌ 완전 배제 슬픔에 잠긴 유족이나 조용한 환경의 시니어에게 기계식 타격음은 불필요한 소음과 거부감을 줌 ➔ 음소거(무음) 유지
사이버 글리치 텍스트
(Scramble with !@#$)		 ❌ 완전 배제 시니어 사용자에게 시스템 오류/깨짐으로 오인될 위험 ➔ 단아하고 정갈한 페이드인 & 스트로크로 대체
다크 잉크블랙 배경
(oklch 0.08)		 ❌ 완전 배제 이어봄 브랜드 고유 자산인 소프트 웜 크림(#FBF9F5) 바탕색을 100% 유지
한지 노이즈 질감
(Fractal Noise)		 ⭕ 채택 소프트 웜 크림 배경 위에 극미세 한지(Hanji) 질감(`opacity: 0.015`)을 얹어 종이의 온기와 깊이감 부여
종이 모서리 접힘
(Corner Fold)		 ⭕ 채택 유언장, 엔딩노트, 공문서 등 기록물의 아날로그 감성을 4박스 카드 우측 하단에 단아하게 적용
호버 확장 디바이더 라인 ⭕ 채택 카드 호버 시 48px 골드/그린 라인이 100%로 스무스하게 늘어나는 절제된 모션 적용

📐 2. 풀페이지 스냅스크롤(100dvh) 융합 구조

interface 템플릿의 일반 세로 스크롤 방식 대신, 이어봄의 풀페이지 스냅 스크롤(100dvh) 3섹션 아키텍처를 완벽하게 유지하면서 화면을 완성합니다.

[섹션 0] 메인 히어로 (100dvh 스냅)

• 배경: 소프트 웜 크림(#FBF9F5) 바탕 + 극미세 한지 질감 노이즈.
• 좌측: "존엄하고 따뜻한 봄날을 함께 이어갑니다" 명조 헤드라인의 정갈한 등장.
• 우측: 나룻배 비주얼 카드에 부드러운 페이드 테두리와 서정적인 줌 애니메이션.

[섹션 1] 4박스 진입 구조 (100dvh 스냅)

• 박스①(생전 준비) & 박스②(임종 및 사후 정리): 우측 하단 한지 접힘(Corner Fold) + 호버 시 100% 확장 디바이더 라인 + 클릭 시 미니 풀스크린 오버레이(BoxDetailOverlay) 오픈.
• 박스③(Guest) & 박스④(파트너): 정갈한 단일 라인 바로가기 형태 유지.

[섹션 2] 플랫폼 정보 푸터 (100dvh / auto 스냅)

• 다크 딥 네이비(#1A2B4C) 바탕에 법정 약관 및 보호책임자 실연락처 정보가 단정하게 정렬된 신뢰의 마무리.

🗂️ 3. 4박스 카드(EntryBoxes) 디테일 개선

EntryBoxes.tsx의 카드를 아날로그 기록물처럼 고급스럽게 다듬는 핵심 CSS & 인터랙션 기법입니다.

📜 종이 모서리 접힘 (Corner Fold) & 디바이더 확장 라인
Pure CSS 구현

복잡한 자바스크립트 라이브러리 없이 순수 CSS만으로 가볍고 안정적으로 구현할 수 있습니다.

/* 1. 카드의 우측 하단 아날로그 종이 접힘 효과 */
.corner-fold {
  position: absolute;
  bottom: 0;
  right: 0;
  width: 24px;
  height: 24px;
  overflow: hidden;
}
.corner-fold::after {
  content: '';
  position: absolute;
  bottom: 0;
  right: 0;
  width: 32px;
  height: 32px;
  background-color: var(--secondary-color); /* 배경색과 동일 */
  transform: rotate(45deg) translate(16px, 16px);
  border-top: 1px solid var(--border-color);
  border-left: 1px solid var(--border-color);
}

/* 2. 호버 시 골드/그린 디바이더 라인 확장 */
.card-divider {
  width: 48px;
  height: 2px;
  background-color: var(--accent-gold);
  transition: width 0.4s cubic-bezier(0.4, 0, 0.2, 1);
}
.entry-card:hover .card-divider {
  width: 100%;
}
