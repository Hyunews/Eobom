📌 1. 서비스 개요 및 비전

  • 도메인: 장례식장, 봉안당(납골당), 수목장, 해양장 맞춤 탐색, LBS 현위치 기반 검색, 공시 견적 비교, VR 360 사이버 답사, 1-Touch 답사 예약
  • 대응 화면 ID: SCR-004 (FacilityPage.tsx, KakaoMapModal.tsx, PriceCompareModal.tsx, BookingModal.tsx)
  • 핵심 가치: 장례 비용 정보 비대칭 해소, 10분 내 최적 안식처 검색, 편리한 답사 예약 대행
  • 상업적 이용 법률 승인: ⚖️ 보건복지부 e하늘 Open API & 카카오 로컬 API 100% 합법적 영리 이용 검토 완료 (공공데이터 이용법 제3조 준수)

🔍 2. 더미 데이터 5종의 실제 구현 가능성 및 상세 기획 판단

현재 프론트엔드 코드에 포함된 5가지 핵심 데이터 항목은 기술적/비즈니스적으로 100% 실제 구현이 가능하며, 서비스의 본질적인 경쟁력이므로 모두 '유지'합니다.

1️⃣ [항목 1] 별점 (Star Rating) 유지 확정

실제 구현 기술 방안: 단순 외부 평점이 아닌, 이어봄 플랫폼을 통해 실제 답사/상담/장례를 완료한 검증된 이용자만 리뷰 및 별점(1.0~5.0)을 작성할 수 있는 자체 리뷰 DB(facility_reviews) 구축. AVG(rating) 산술 평균 수치로 실시간 업데이트.

초기 운영 전략: 초기에는 지자체 및 보건복지부 공시 서비스 만족도 수치를 기본 부여하고 실이용 리뷰 5건 이상 누적 시 유저 평점 가중치로 자동 전환.

2️⃣ [항목 2] 주소 및 위경도 (Location & Address) 유지 확정

실제 구현 기술 방안: 카카오 로컬 REST API (`query=장례식장`) 및 Kakao Maps SDK 100% 연동. 사용자의 현위치(`navigator.geolocation`)를 수신하고 하버사인(Haversine) 거리 계산 로직으로 5km, 10km, 20km 반경 동적 필터링.

3️⃣ [항목 3] 견적 비교 및 예상 기본 비용 (Estimate & Pricing) 유지 확정 (USP)

실제 구현 기술 방안: 보건복지부 `e하늘장례정보시스템` 공공 Open API 연동 (핵심). 전국 장례식장의 표준 시설 사용료(빈소/안치실/입관실) 및 장례 용품 공시 가격 데이터를 실시간 무상 수집. 제휴 파트너 시설의 경우 5대 세부 항목 실시간 분해 & 패키지 할인가 노출.

4️⃣ [항목 4] 특징 해시태그 (Hashtags) 유지 확정

실제 구현 기술 방안: 시설 속성 DB(facility_tags) 연동. 공공데이터의 객관적 속성(주차대수, 24시간 여부, 수목장 종류)과 관리자 입점 등록 체크박스 조합. 태그 클릭 시 모달 필터링 연동.

5️⃣ [항목 5] 답사 예약 (Tour Booking) 수익화 접점

실제 구현 기술 방안 (2단계 하이브리드 예약):

  • 제휴 파트너 시설: 유족의 답사 신청 즉시 장례식장/수목장 사업자 전용 알림톡 및 파트너 어드민 웹으로 예약 정보 자동 전송.
  • 비제휴 시설: 신청 접수 시 이어봄 전담 해피콜 상담원이 유선으로 장례식장에 대신 답사를 예약해 주는 대행 예약 서비스 운영.

🗺️ 3. 전국 장례식장 데이터 구축 및 노출 전략 (하이브리드 디렉토리 모델)

초기 데이터 부족(Cold Start) 문제를 예방하기 위해 전국의 모든 장례식장을 첫날부터 검색할 수 있는 하이브리드 디렉토리 모델을 채택합니다.
