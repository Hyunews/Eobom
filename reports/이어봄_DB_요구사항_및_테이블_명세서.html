🗃️ DB 요구사항정의서 및 테이블 상세 명세서 (Table Dictionary)

이어봄 플랫폼의 데이터베이스 기능/비기능 요구사항 정의 및 전체 10개 핵심 테이블의 물리 컬럼 데이터 구조 사전

1. 데이터베이스 요구사항 정의서 (DB Requirements)

1) 기능적 요구사항 (Functional Requirements)

  • FR-DB-01 [트랜잭션 무결성]: 시설 예약 및 결제, 유언장 작성 시 ACID 트랜잭션 철저 보장.
  • FR-DB-02 [데이터 암호화]: 유언장 본문 및 유산 자격 증명은 DB 저장 전 애플리케이션단 AES-256-GCM 필드 암호화 적용.
  • FR-DB-03 [가변 자산 구조]: 플랫폼별 유산 계정 데이터 저장을 위해 PostgreSQL JSONB 타입 활용.
  • FR-DB-04 [위치 공간 인덱스]: 장례식장/추모공원의 위경도 기준 반경 검색 최적화를 위해 PostGIS 또는 Spatial Index 적용.

2) 비기능적 요구사항 (Non-Functional Requirements)

  • NFR-DB-01 [성능 및 가용성]: 읽기 트래픽(부고장/시설 검색) 1,000 RPS 이상 처리, 99.9% 서비스 가동률.
  • NFR-DB-02 [백업 & 복구]: 일일 자동 풀 백업(Daily Full Backup) 및 트랜잭션 로그 실시간 스트리밍(Point-in-time Recovery).

2. 전체 10개 테이블 명세서 (Table Dictionary)

1) users (회원 기본 정보 테이블)

컬럼명 (Column) 데이터 타입 길이 제약 조건 Null 허용 기본값 암호화 설명
id VARCHAR 36 PK No UUID() - 회원 고유 식별자
email VARCHAR 100 UK No - - 로그인 이메일 계정
password_hash VARCHAR 255 - No - BCrypt 비밀번호 해시값
name VARCHAR 50 - No - - 회원 실명
phone VARCHAR 20 - No - - 휴대폰 번호
role VARCHAR 20 - No 'USER' - 권한 (USER, COUNSELOR, ADMIN)
created_at TIMESTAMP - - No NOW() - 가입 일시

2) guardians (지정 수령인 / 보호자 테이블)

컬럼명 (Column) 데이터 타입 길이 제약 조건 Null 허용 기본값 암호화 설명
id VARCHAR 36 PK No UUID() - 수령인 고유 ID
user_id VARCHAR 36 FK (users.id) No - - 작성 회원 ID
name VARCHAR 50 - No - - 수령인 성명
phone VARCHAR 20 - No - - 수령인 연락처
relationship VARCHAR 30 - No - - 관계 (자녀, 배우자 등)
is_verified BOOLEAN - - No false - 본인 인증 완료 여부

3) wills_notes (디지털 유언장 & 엔딩노트 테이블)

컬럼명 (Column) 데이터 타입 길이 제약 조건 Null 허용 기본값 암호화 설명
id VARCHAR 36 PK No UUID() - 유언장 고유 ID
user_id VARCHAR 36 FK (users.id) No - - 작성 회원 ID
title VARCHAR 200 - No - - 유언장 제목
encrypted_content TEXT - - No - AES-256 암호화된 유언장 본문
release_condition VARCHAR 50 - No 'DEATH_VERIFIED' - 공개 조건 (사망인증/지정일)
is_released BOOLEAN - - No false - 공개 열람 활성화 여부

4) will_files (유언장 미디어 파일 테이블)

컬럼명 (Column) 데이터 타입 길이 제약 조건 Null 허용 기본값 암호화 설명
id VARCHAR 36 PK No UUID() - 파일 고유 ID
will_id VARCHAR 36 FK (wills_notes.id) No - - 유언장 ID
file_url VARCHAR 500 - No - - S3 저장 객체 URL
file_type VARCHAR 50 - No - - 파일 형식 (audio/mp4, video/mp4)

5) digital_estates (디지털 유산/계정 테이블)

컬럼명 (Column) 데이터 타입 길이 제약 조건 Null 허용 기본값 암호화 설명
id VARCHAR 36 PK No UUID() - 유산 항목 ID
user_id VARCHAR 36 FK (users.id) No - - 소유 회원 ID
platform_name VARCHAR 100 - No - - 플랫폼명 (Naver, Kakao 등)
action_type VARCHAR 30 - No 'DELETE' - 처리방침 (DELETE, TRANSFER, MEMORIAL)
encrypted_credentials TEXT - - Yes NULL AES-256 암호화된 계정 자격 증명

6) facilities (장례/추모 시설 DB 테이블)

컬럼명 (Column) 데이터 타입 길이 제약 조건 Null 허용 기본값 암호화 설명
id VARCHAR 36 PK No UUID() - 시설 고유 ID
name VARCHAR 150 - No - - 시설 명칭
category VARCHAR 50 - No - - 카테고리 (장례식장/봉안당/수목장)
address VARCHAR 255 - No - - 도로명 주소
latitude DOUBLE - - Yes NULL - 위도 좌표
longitude DOUBLE - - Yes NULL - 경도 좌표

7) facility_reviews (시설 후기 테이블)

컬럼명 (Column) 데이터 타입 길이 제약 조건 Null 허용 기본값 암호화 설명
id VARCHAR 36 PK No UUID() - 리뷰 ID

user_id VARCHAR 36 FK (users.id) No - - 작성자 ID
rating INT - - No 5 - 평점 (1~5점)
comment TEXT - - No - - 리뷰 내용

8) reservations (상담 및 시설 예약 테이블)

컬럼명 (Column) 데이터 타입 길이 제약 조건 Null 허용 기본값 암호화 설명
id VARCHAR 36 PK No UUID() - 예약 고유 ID

9) obituaries (모바일 부고장 테이블)

컬럼명 (Column) 데이터 타입 길이 제약 조건 Null 허용 기본값 암호화 설명
